# M6.0c · 安全节点恢复、战备结算与装甲工坊

> 2026-11-12 · **开发分支功能，未部署线上** · 基于 [M6.0b 三幕远征](ARCHITECTURE_M6_THREE_ACT.md)。  
> 产品背景：[Roguelite 核心 PRD](https://github.com/kk518/endless-swarm/blob/docs/prd-v2-m6-m8-planning/docs/PRD_ROGUELITE_CORE_LOOP.md)；英雄和新武器暂不加入内容池。

## 1. 交付目标：玩家 16 分钟失败后不再白玩

**本轮真实接入的最小闭环**：

```text
基地（选五波/三幕；战备余额 + 装甲工坊）
   → 开始三幕远征，生成唯一 runId，记录关卡/武器/HP/随机状态
   → 遭遇结束 → 生成并保存已抽定的战术卡或路线 → 安全阶段做决定
   → 保存下一遭遇起点 → 允许浏览器关闭/重进后继续
   → 胜利 / 失败 → 按有效游玩进度一次性结算战备
   → 基地花战备升级装甲（最多三级）
   → 下一局出击：初始生命上限真实 +1/+2/+3
```

对局内 XP、四普通武器、各自 Lv.5 进化、英雄/专武预留驱动和三幕阶段节奏没有加入额外升级弹窗。

## 2. 安全节点快照（不是保存任何一帧）

### 存档时机
1. **实验远征开始**：关卡 0 起点可保存；
2. **阶段结束进入安全奖励页面时**：先抽定卡牌/计算路线候选，再写存档，最后才显示页面；
3. **玩家选择卡牌或路线后**：记录下一遭遇的**干净起点**及加成，阶段奖励不能再次操作；
4. **失败/通关结算成功后**：先写入战备到账流水与余额，再清除该局可恢复快照。

只有三幕实验远征使用进度快照，五波原型依然可以按原方式反复开局，不提供逐波断点。

### 保存的字段
- `schemaVersion: 1`、唯一 `runId`、`campaignId`、关卡序号、阶段状态和本局随机种子；
- `RunBuild`：持有的四普通武器、卡牌历史、伤害/射速/速度/防御数值与当前 HP；
- `GrowthState`：XP、已装备武器等级、进化状态；当前自动训练倾向；
- 四个随机流的**游标状态**：战斗、抽卡、事件、视觉；
- 时间、击杀、最高连杀、回收/补给统计及下一阶段的额外敌群压力；
- 在安全奖励时储存**已经抽出的卡牌 ID**，刷新页面不能重新投骰抽卡；路线则按当前血量恢复合法选项。

`runSafeSave.ts` 纯数据校验包括：模式一致、状态只在奖励页或遭遇起点、不能假造英雄/第五把武器/过高等级、不合法 HP 或 RNG、不属于卡池的卡、重复卡牌选项等。错误版本/损坏快照不予恢复。

**不保存 Phaser 的敌人、精灵、子弹、特效**；继续时在安全节点附近重建干净战场。这是有意的产品设计，不是无限制即时存档。

### 存储位置及风险
- `localStorage` 键：`endless-swarm-expedition-safe-v1`。
- 仅本机同源浏览器，**非云同步**；清除浏览器数据、无痕窗口、跨设备或迁移域名时可能丢档。
- 如写入失败，UI 提示存档不可用，不能宣称存储成功。
- 当前不存在多标签页的跨进程原子锁或服务端反作弊。**同一设备同时开两页游玩/购买可能导致并发覆盖**；正式发布前要做存储所有权或单标签锁、防并发结算。该限制不是由单次写入能够自动解决的。
- 此版本的安全节点快照只在敌群阶段之间保存；中途关页面时会从最近**已存起点或奖励**恢复，无法恢复关闭瞬间的位置与弹幕。

## 3. 通用战备数据和一次性结算

`metaProgression.ts` 的版本化 `MetaProgress`：
- `schemaVersion=1`；
- `warData`：通用战备数据；
- `armorRank`：永久装甲级别；
- `settledRuns`：已结算本局 ID 去重流水。

有效出击需达到 **至少 30 秒战斗且至少击杀 5 只虫**。示例初版公式（平衡待定）：

```text
战备 = 5
     + min(有效战斗分钟, 25) × 3
     + min(已完成遭遇数, 24) × 3
     + min(12, floor(击杀/20))
     + (胜利 ? 20 : 0)
```

- 失败按真实有效战斗进度也可获取战备；胜利有额外 20 点，秒退无法刷钱；
- 本局 ID 与余额在一个本地存储记录内写入；重复调用同一个 `runId` 将返回**0 新收益**；
- 若保存账本失败，前端显示未保存、**不清除可能可恢复的远征存档**；
- 玩家结算后显示该局所得与当前总战备。

**限定**：本地客户端不是抗篡改或强事务数据库；跨标签并发覆盖仍是未来 P0，不能将当前 ledger 等同于服务器防刷钱。

## 4. 装甲工坊

- 一个永久装备槽：**基础装甲**，Level 0→1→2→3；
- 升级分别需要 `25 / 55 / 100` 点战备；
- 每级仅在**之后开始的新对局**增加 1 点最大生命与初始生命，最多 +3；
- 不修改当前尚未结束/已保存的远征构筑；
- 无资源或已满级时按钮不可用；
- 购买扣费和装备等级同时序列化，写入失败不会提示购买成功；
- 仍未开放战区专属材料、完整四槽装备工坊、英雄和永久科技树。

存储键 `endless-swarm-meta-v1`。老用户的击杀最高记录另有存储键，仍沿用旧值，不互相覆盖。

## 5. UI 行为

- 首页展示战备总额、基础装甲等级、下次升级费用与购买入口；
- 若发现合法安全存档，显示**继续远征 · 当前段数**；
- 若用户已存远征却选择新局，弹出明确的**放弃旧存档确认**；取消不丢进度；
- 如果继续时存档版本不兼容，停留主页并说明，避免进入缺失状态的战斗；
- 刷新并继续安全奖励页后，**原三选一卡片不变**；
- 结算屏展示战备增加值、当前余额，失败也能看到下一次升级目标；
- 所有动作仍是单指可触，普通战斗中经验升级保持自动触发。
