# 《无尽虫潮》英雄军械库、武器蓝图与局内选卡规则 PRD v1.0

> 2026-11-12 · **规划中，未实现** · 面向 M6.2 首批英雄 Build 垂直切片与 M7 长期解锁  
> 上位需求：[英雄武器总 PRD](PRD_HERO_WEAPON_SYSTEM.md) · [首批可玩切片](PRD_HERO_BUILD_VERTICAL_SLICE.md) · [三幕 Roguelite](PRD_ROGUELITE_CORE_LOOP.md) · [战区资源工坊](PRD_BATTLEFIELDS_EQUIPMENT.md)  
> 当前已实现基线：M5.2 自动 XP/自动进化、M5.3 可见虫潮。**英雄、专属武器、蓝图解锁、模组融合、三幕长局都属于未来功能**。文中数字是平衡候选值而非实测结果。

## 0. 产品目标：让“解锁”、“养成”、“凑 Build”互相促进

玩家从一次失败获得的不只是战备货币，还应该可能得到一张**新武器蓝图的解锁资格**或推进某位英雄的熟练度。回基地可以确定性地解锁自己想玩的装备，下一局在不同的战区选择不同的路线，把它们组合成新 Build。

**核心分工**：
- **永久收集层**：解锁英雄、普通武器蓝图、英雄专武改造路线的“可选择资格”，以及少量底盘/装备科研数值；
- **单局成长层**：开局英雄自带 1 把专武，普通武器初装 1 把，通过阶段奖励最多装备 4 把；武器用战斗 XP 自动升级；
- **构筑层**：玩家在安全节点亲手选择核心/辅助模组、英雄专武改造、主融合与觉醒；
- **经济层**：战备数据和战区素材在有效失败/通关后结算，资源没有抽卡转化、购买失败或保底付费问题。

**解锁不是免费带上**：解锁一把普通武器，只是将它加入未来战局的可用候选和允许的初装清单（初装自由选择按 M7.1 扩展），不等于下一局开局自动同时装备它。英雄专属武器不能在其它英雄的掉落池中出现。

## 1. 军械库与英雄选择界面

### 1.1 出击前信息架构

```text
战备基地
  ├── [战区地图] 选择资源目标 / 战区风险 / 当前可解锁内容
  ├── [英雄档案] 英雄被动 / 专武 / 推荐标签 / 弱点 / 解锁条件
  ├── [武器蓝图] 可用普通武器 / 图鉴 / 解锁需求 / 武器进化材料
  ├── [机甲整备] 底盘 / 初装武器 / 当前永久装备等级
  ├── [工坊研发] 战区素材 → 基础装备强化；战备数据 → 轻量科技
  └── [开始出击] 已选英雄、底盘、初装、训练倾向的简要摘要
```

原则：**首次打开直接可以出击**，默认凯恩 + 哨兵 + 步枪；非首次返回基地时优先展示下一目标装备所缺资源和可进入的对应战区。不做“必须在 6 个栏目逐一打勾才能出击”的流程。

### 1.2 英雄与底盘必须分别选择
- 英雄 = 被动、英雄级专武、角色台词/视觉身份与可选专武觉醒；
- 底盘 = 哨兵/游隼/壁垒的基础速度和生存取舍；
- 任何英雄都可驾驶已解锁底盘，不能偷偷把后解锁角色设为全方面更高属性；
- 出击时生成配置快照，局外更换英雄不能修改正在进行的一局；
- 目前规划六英雄，但 **M6.2 只验证凯恩、灰烬、伊芙**，之后增加零/堡垒/薇拉。

## 2. 英雄解锁：失败后也可能离新玩法更近

### 2.1 确定性解锁，不做英雄抽卡

| 英雄 | 默认可用 | 初版规划条件（满足任一即可，数值待平衡） | 解锁价值 |
|---|---|---|---|
| 凯恩 | 是 | 免费 | 默认均衡/单体、建立教程基准 |
| 灰烬 | 否 | 在任一战区完成第一幕 1 次，**或**花费 60 战备数据 | 燃烧传染与爆破型 Build |
| 伊芙 | 否 | 首次击败一名精英且完成相应结算，**或**花费 80 战备数据 | 电弧节点与控制型 Build |
| 零 | 否 | M7.0 追加明确的机动挑战/战备解锁路径 | 移动反击 |
| 堡垒 | 否 | M7.0 追加明确的阵地挑战/战备解锁路径 | 站桩反击 |
| 薇拉 | 否 | M7.1 追加与精英猎杀相关的解锁路径 | 标记与毒素 |

**可用性优先**：原型评测模式应允许三个首批英雄直接选择，避免 QA 必须刷很多局才能验证；面向真实玩家时才应用以上解锁条件。付费货币、英雄碎片、限时兑换与每日登陆不在规划内。

只达成成就条件时**直接解锁英雄，不再扣费**；用资源购买是另一条替代路径，已解锁不能重复付费。不能要求“先选灰烬完成任务才能解锁灰烬”形成死锁。

### 2.2 英雄熟练度
- 每次以该英雄完成有效战斗，可积累该英雄熟练度；
- 熟练度只解锁**战术说明、角色外观、可选专武改造路线或不同初装方案**，不无限加英雄基础伤害；
- 首批 M6.2 不需要完整熟练度经验条和成就页，可先记录英雄有效结算次数；M7 再做可见进度；
- 熟练度与通用战备是两条不同用途的**进度记录**，不能把熟练度当成第四种可消费地区素材。

## 3. 普通武器蓝图：永久扩充可玩策略

### 3.1 规则和稀有度
- 蓝图表示**获得该武器在局内奖励池出现的资格**，不是永久装备一个额外普通槽；
- 武器 Lv.1–5 仍在本局自动成长、重开归零；进化材料仍来自本局合法奖励；
- 武器本体不分“橙枪必然碾压白枪”的线性品质；稀有度主要附着在**模组、英雄专武觉醒、主融合**上；
- 先维护已实现的 4 把武器，再新增重型旋转机炮、低温投射器；后续逐步解锁其余武器，不一次放入 12 把扰乱 Build 概率。

### 3.2 首批新增两把蓝图（规划初值）
| 蓝图 | 取得条件（初始建议） | 为什么选它 | 适配英雄 |
|---|---|---|---|
| **重型旋转机炮** | 在钢铁遗迹完成一项精英挑战，或用 40 战备 + 18 合金解锁 | 强化展开蓄速、站位与持续压制 | 凯恩/堡垒；其他英雄也合法 |
| **低温投射器** | 在感染巢穴完成任意一次高风险目标，或用 40 战备 + 18 生体样本解锁 | 冰区控制、雷霜融合的必要组件之一 | 伊芙；灰烬/凯恩也合法 |

**解锁来源不能先于产地出现**：M6.2 首批武器应基于 M6.1 已开放的合金与样本。玩家没有挑战能力时，能通过反复完成普通有效对局攒资源解锁，不强制打赢高难精英。

### 3.3 解锁规模对随机性的影响
- 已解锁武器超过当前单局可用槽位后，局内池按已装备标签、战区主题和玩家出击前选择的构筑愿望进行**软推荐**；
- 不按英雄强制禁用不推荐武器；只缩窄**无效候选**，不缩窄合法玩法；
- 开局无需选择“只允许抽到这 4 把”的硬锁池，也不要让同一套最优起手每次固定出现；
- 若武器蓝图越解锁越难凑齐 Build，应优先优化合法性过滤、定向补缺和转型选项，不靠无限刷新券解决。

## 4. 装备工坊、科技、英雄武器三者不可混用

| 系统 | 是否永久 | 升级发生在哪 | 增益对象 | 主要消费 |
|---|---|---|---|---|
| 武器蓝图解锁 | 是 | 基地 | 未来局内可选普通武器列表 | 战备/对应地区资源或挑战 |
| 武器框架等工坊等级 | 是 | 基地 | 所有合适装备的开局基础参数 | 战备+地区资源 |
| 轻量科技树 | 是 | 基地 | 低上限的全局属性/情报 | 通用战备 |
| 英雄熟练度 | 是 | 战后累积、基地查看 | 外观、情报、可选改造分支 | 有效战斗记录 |
| 普通武器 Lv.1–5 | 否 | 战斗中自动 XP | 本局该武器的射速/威力/机制 | XP |
| 普通武器进化 | 否 | 满足 Lv.5+战术配方时自动 | 本局新射击机制 | 局内选择的前置卡 |
| 英雄专武改造/觉醒 | 否 | 自然阶段奖励 | 本局专武的新机制 | 本局大奖励选择 |
| 主融合与模组 | 否 | 幕间重要奖励 | 多种武器之间的机制联动 | 本局核心/辅助/主融合槽 |

**避免数值爆炸**：武器框架、轻量科技和底盘可以有有限的基础加成，但不能与英雄熟练度、觉醒、稀有度一起乘出无限数值。工坊是玩家失败后慢慢变强的渠道，真正的“逆天 Build”来自当局组合而非刷钱后开局无敌。

## 5. 高稀有奖励应当改变玩法

### 5.1 奖励四个等级

| 品级 | 典型奖励 | 是否可在第一幕获得 | 新鲜感来源 |
|---|---|---|---|
| 常规 | 可用武器、通用攻防小模块、补给 | 是 | 构筑基础与稳定性 |
| 精良 | 凝霜继电器、爆焰点火器、英雄专武初阶改造 | 是，稀有时段 | 攻击状态改变 |
| 史诗 | 雷霜封锁、炼狱引爆、强力跨武器核心 | 第二幕符合前置后 | 首次真正改变输出机制 |
| 传说 | 审判者/地狱熔炉/风暴塔觉醒 | 第三幕符合前置后 | 英雄高光时刻 |

**不能直接承诺“传说出现概率 1%”**：英雄觉醒和主融合不是靠无尽抽卡撞运气，而是满足条件后进入正确阶段的合法候选。品级主要表达**机制复杂度与获得时间窗口**，不是每级伤害高 2 倍。

### 5.2 典型奖励的信息设计
一张卡应包含：
- 分类标识：**武器 / 进化材料 / 核心模组 / 辅助模组 / 融合 / 英雄专武改造 / 觉醒**；
- 清晰的**前置条件**与已满足状态（例如 `电弧 ✔ + 冰霜 ✔`）；
- 选择后具体会改变什么行为，例如“电弧命中减速虫后向 3 名敌人传播减速”；
- 对应的槽位剩余数、现有核心标签；
- 一条明确代价：占用核心模组位、主融合位或一次阶段重大奖励，避免“没有代价的免费史诗”。

颜色可以辅助识别品级，但不能仅用颜色区分卡片类型、前置和稀有度。

## 6. 分阶段奖池与真实 Build 可达性

### 6.1 八次重要决策的功能分配
沿用 [首批可玩切片 D1–D8](PRD_HERO_BUILD_VERTICAL_SLICE.md)：

| 决策 | 候选池定位 | 至少提供的合法方向 |
|---|---|---|
| D1 第一幕早段 | **武器/保命/基础组件** | 未满槽时优先提供合法第二武器的机会 |
| D2 第一幕中段 | **风险路线二选一** | 精英配方路线 vs 安全补给路线 |
| D3 第一幕精英后 | **英雄改造/武器配方/精良模组** | 优先一次合法英雄专武改造机会 |
| D4 第二幕早段 | **武器/模组/转型** | 已选前两个标签相关协同候选 |
| D5 第二幕中段 | **路线二选一** | 高风险稀有模块 vs 安全战备/修复 |
| D6 第二幕精英后 | **主融合高光** | 若满足融合配方，可见相应主融合；否则提供缺件 |
| D7 第三幕早段 | **英雄觉醒高光** | 已有改造时，当前英雄觉醒进入合法候选 |
| D8 Boss 前 | **补缺与生存兜底** | 不把全部候选都做成已满槽的无效卡 |

**D1–D8 只有 6 次奖励与 2 次路线选择**，不代表每波后还额外出现 8 次小面板。所有 XP 自动升级与以上幕间大决策是不同层。

### 6.2 合法候选筛选（先于随机）
候选必须全部满足：
1. 已解锁并且在当前阶段可用；
2. 当前英雄或已装备武器可以真正使用；
3. 核心/辅助/普通武器/融合槽位未满，或者具备明确且无额外弹窗的合法替换流程；
4. 非一次性已获项目、非已进化/已觉醒重复项目；
5. 前置材料齐备；如果不齐备，提供的是**前置组件卡**而不是不可选的灰卡；
6. 对当前战斗真实有效，不会提供空数值、错误叠加或不适用机制。

若合法候选不足三项，先从通用功能池补足；再不足时可少于三项并在 UI 明示，**不生成复制卡或非法卡来凑三选一**。

### 6.3 Build 方向保护，但不固定最优套路
- 三个候选位的功能角色为**当前协同 / 转型 / 通用兜底**；展示顺序打乱。
- 玩家可在出击前设定一个**构筑愿望**（默认英雄推荐），影响奖励权重，不锁池。
- 连续两次有机会选协同却未见合法相关组件时，第三次至少应出现一个可用**相关组件**，而不是免费给最高品级融合；
- 若实际装备标签已经转向，之后的协同权重应依据当前 Build 重算，不能始终向开局英雄推荐武器；
- 已经解锁大量蓝图时，不应让同一英雄的融合可达率持续随解锁数下降；
- 若两个主融合均满足前置，D6 必须展示两个合法选项，让玩家自主选其一（主融合仍只能有一个）；
- 不保证每局凑齐全部终极进化；**高光可达 ≠ 每局必给最优卡**。

## 7. 英雄专武的局内成长规则

### 7.1 首轮 M6.2 只做一次改造和一次觉醒
- 每位英雄自带基础专属武器；不能在其它英雄卡池抽到；
- **D3**：至少给一次当前英雄的专武改造合法候选，但玩家可以选择其它同价值奖励；
- **D7**：若已获得改造，可将该英雄觉醒作为合法候选；**未改造则提供改造而非空觉醒**；
- 改造和觉醒都是玩家在幕间有代价的选择，不是随着 XP 等级自动发生；
- 觉醒只在本局生效，重新出击复原；英雄熟练度可永久解锁未来的不同改造路线（M7）；
- 同局只有一次觉醒，专武的自动攻击必须在游戏暂停/恢复、胜利/死亡后正确结束。

### 7.2 后续多分支（M7+，不提前进 M6.2 卡池）
| 英雄专武 | 可选发展方向 A | 可选发展方向 B | 一局规则 |
|---|---|---|---|
| 凯恩·审判者 | 贯穿追猎：直线串联多个高价值目标 | 弱点处决：对带弱点目标积累蓄能爆裂 | 二选一 |
| 灰烬·地狱熔炉 | 传播熔火：燃烧更易传给密集虫群 | 定点爆燃：对灼烧精英蓄热爆发 | 二选一 |
| 伊芙·风暴塔 | 广域电网：扩大多目标控制 | 精准超载：减少中继范围，增加重点目标放电 | 二选一 |

**两条方向不是线性升级树**；玩家可以跨局试另一方向。不能让“更高熟练度”直接同时获得 A+B 全部效果。

## 8. 单局构筑示例：同一英雄可以反复玩

**灰烬火焰融合局**：初始火焰 → D1 取得散射 → D3 改造地狱熔炉 → D4 拿爆焰点火器 → D6 主融合炼狱引爆 → D7 熔炉觉醒 → D8 补生存 → Boss。特点是先点燃、再引爆，密集清场强。

**灰烬电弧转型局**：初始火焰 → D1 电弧 → D3 改造熔炉 → D4 低温投射器 → D6 雷霜封锁（若有足够前置） → D7 熔炉觉醒。特点是火焰提供近身保底，冰电提供控制；灰烬的英雄被动较不容易持续触发，但不会因此禁止这条路线。

**凯恩部署压制局**：步枪 → D1 重机炮 → D3 审判者改造 → D4 贯穿相关组件 → D6 优先重要单体/火力核心而非硬塞不满足前置的融合 → D7 审判者觉醒。即使没融合也应该能靠可用的武器机制打到 Boss，而非被系统判定 Build 失败。

这几种是**目标 Build 路径**；D1/D4 抽到哪些武器、D2/D5 选择哪条路线仍受受控随机影响，不是固定开局脚本。

## 9. 结算：把失败和 Build 高光都表现出来

结算屏建议优先展示：
1. **本局英雄及其专武觉醒**（是否觉醒、发生了什么关键动作）；
2. **本局核心 Build**（主要普通武器、进化形态、主融合、模组标签），可以生成简短标签，例如「灰烬 / 炼狱引爆 / 热能爆裂」；
3. **表现摘要**（当前到达的幕/遭遇、击杀、时间、Boss 结果）；
4. **合法战利品**（通用战备、合金/样本/晶体，分别标出主要产地），同一局只发一次；
5. **下一次目标**（当前缺多少材料可升级哪件装备/解锁哪位英雄/哪把蓝图）；
6. **再来一把 / 换英雄 / 去工坊 / 切战区**，快速重新出击。

不要求玩家在结算后再点一个“领取”按钮，不用多层强制广告/签到阻断重开。一次失败至少让玩家知道：这局的 Build 强在哪里、为什么失败、离下一项解锁还有多少进度。

## 10. 内容预算、版本分期与验收

| 阶段 | 主要交付 | 明确不做 |
|---|---|---|
| **M6.2 首批垂直切片** | 3 英雄/专武、原 4+新 2 普通武器、2 融合、D1–D8 奖励、合法池/配方、一次改造一次觉醒 | 6 英雄全量、12 武器全量、英雄熟练度完整 UI |
| **M7.0 持久军械库** | 部分新英雄、蓝图永久解锁、科技/机甲、战区资源与工坊深化 | 不把普通武器蓝图做成一次性花钱买装备槽 |
| **M7.1 丰富 Build** | 6 英雄目标、12 武器目标按实际内容质量逐渐加入，专武多分支/挑战与图鉴 | 不增加无限战力树或付费抽卡 |

### 产品验收
- ARM-01：一局可以合法装备 4 普通武器 + 自己英雄的 1 专武，不能拿到别的英雄专武。
- ARM-02：三位英雄有明显不同的被动/专武机制，非推荐武器合法且不会永久失去成长机会。
- ARM-03：武器蓝图的局外解锁**只改变候选资格**，不会直接赠送 4 把武器或 Lv.5 进化。
- ARM-04：D1–D8 实际呈现 6 次重大奖励 + 2 次路线抉择，XP 自动升级不再插入模态面板。
- ARM-05：合法候选不含满槽、无前置、错英雄、重复觉醒与无效卡；允许相关组件与转型机会。
- ARM-06：D3 的专武改造/D7 的觉醒条件真实生效，没改造时不会出现空白觉醒；同局最多觉醒一次。
- ARM-07：两融合都满足时在同一选择窗口合法出现且只能选择一条；未满足时不占候选。
- ARM-08：英雄/蓝图/装备/科技与当局 XP 等级分开保存/重置，切换英雄不损失其它永久资产。
- ARM-09：战备/地区资源结算幂等、购买扣费可复算；达到成就条件直接解锁，不重复付费。
- ARM-10：结果页能说清本局英雄+武器+模组+融合形成了什么玩法，以及下一步要解锁什么。
- ARM-11：首批不同英雄/非推荐 Build 能在入门战区存在合法通关路径；较晚解锁的英雄不是数值上位替代。
- ARM-12：获得更多蓝图后依旧存在真实的构筑目标达成机会，不以无限刷新或付费强保底解决卡池稀释。

### 下一轮实际验证优先级
先用灰烬/伊芙两种完全不同的直接伤害/状态机制验证融合引擎；再验证凯恩是否能提供不依赖融合的单体高光。奖励池的具体掉率、蓝图费用、英雄熟练度和专武 CD，全部等三幕完整局打通后定标。

---

**设计裁决：玩家要能因为“我想玩伊芙雷霜”选择英雄、选择战区、解锁所需武器蓝图，在一局里通过自己的奖励决定凑出 Build。开发应围绕这个玩家目标，而不是围绕做满多少个按钮和角色数量。**
