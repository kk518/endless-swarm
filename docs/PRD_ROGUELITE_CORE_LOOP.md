# 《无尽虫潮》Roguelite 核心玩法重构 PRD：三大体验支柱

> 版本：v1.0（2026-11-11） · 状态：**产品方向修订 / 规划，尚未开发**  
> 当前线上实现：M5.1（5 波、四武器、四进化、局内 XP 升级与频繁三选一）  
> 上位需求：[PRD v2 产品总纲](PRD_V2.md) · [M5.2 无打断升级](PRD_M5_2_NONBLOCKING.md)  
> 相邻需求：[战区资源与工坊](PRD_BATTLEFIELDS_EQUIPMENT.md) · [局外研发与机甲](PRD_META_PROGRESSION.md) · [路线图](ROADMAP_M6_M8.md)

## 0. 最重要的产品决策

用户明确了三个必须优先保证的体验：

1. **每局都新鲜**——不同战区、随机路线、事件、敌方组合与奖励，下一次出击不应只是在同一个圆形场地重新绕圈。
2. **失败也爽**——失败不是白打，有可见的战备与地区材料、装备升级/机甲解锁、明确的下一个目标，玩家有“再来一把”的动机。
3. **Build 上头**——不仅武器数值变大，组合产生真实机制质变；在本局中形成“我自己做出来的强力流派”，愿意尝试其它流派。

**额外确认：单局可以明显加长，现有最长 260 秒战斗不是产品最终局长。**  
本 PRD 将标准完整通关局调整为 **15–20 分钟战斗目标**（结算和自由阅读决策可使总时长稍长），新手可能更早失败，熟练玩家可体验完整三幕。

**两个明确减项**：取消战斗中频繁升级模态弹窗；手机 FPS/性能不作为本轮需求优先级和开发限制。但运行不能崩溃、不能失去输入或损坏进度。

## 1. 产品定位：怎样才像一个完整的肉鸽游戏？

产品形态：单机 H5、手机竖屏、一指控制人形机甲的俯视 2.5D 虫潮生存 **Roguelite**。

**三重循环：**

```text
[长期循环] 地图战区选择 → 出击 → 资源结算 → 装备工坊/科研/机甲解锁 → 下一战区
                      ↓
[单局循环]  三幕虫潮：多轮遭遇 → 可选风险目标/随机分岔 → 阶段奖励 → 精英/Boss → 结算
                      ↓
[短循环]   单手移动/站桩展开 → 武器自动射击 → 击杀 XP → 自动小升级 → 继续射击
```

设计约束：
- 单局乐趣优先于刷钱效率；没有永久装备也必须可以玩、能赢入门战区。
- 单手玩法不增加手动准星、切枪或战斗技能轮盘。
- 随机改变**选择与挑战**，不随机制造无法躲避的死亡。
- 战斗连续性优先：升级 XP 不暂停，**重大选择留在自然阶段结算**，不强制战斗时点卡。
- 不为了延长局长把怪物血量乘三、把波次复制四遍，也不鼓励 20 分钟单调绕圈。

## 2. 长局结构：三幕 / 九个遭遇节点

### 2.1 建议目标节奏（最终可由选战区变体调整）

| 时段（战斗时间） | 局内段落 | 节奏功能 | 玩家感受 |
|---|---|---|---|
| 0:00–2:00 | 第 1 幕 · 登陆 | 了解当局随机敌群与第一把武器；自动 XP 成长 | 很快能打、很快变强 |
| 2:00–4:00 | 第 1 幕 · 突破 | 第一轮路线/风险抉择，争取第二武器或核心模块 | 出现构筑倾向 |
| 4:00–5:30 | 第 1 幕 · 小精英 | 首次明确的强力奖励；第一幕结束 | 得到一次质变 |
| 5:30–7:30 | 第 2 幕 · 压制 | 进场敌种和环境规则改变 | 战场不是纯刷怪 |
| 7:30–9:30 | 第 2 幕 · 分岔 | 风险目标/奖励二选一；积累流派组合 | 开始凑强力 Build |
| 9:30–11:00 | 第 2 幕 · 精英/事件 | 两把武器配合成型，进化条件可追求 | 从普通强化变为机制协同 |
| 11:00–13:00 | 第 3 幕 · 虫巢集结 | 压力升高但有可读的逃生路线 | 构筑成型的火力验证 |
| 13:00–15:00 | 第 3 幕 · 终局准备 | 最后一批成长/配方补救奖励，明确 Boss 预告 | 为最终打法作最后选择 |
| 15:00–17:00/20:00 | 第 3 幕 · Boss | 多阶段技能与短暂反击窗口 | 构筑和走位共同决定胜负 |

此表是**体感节奏目标，不是固定事件倒计时或每局强制打满时长**。初版可以保留现有战斗区域与相机结构，拆分 9 段数据配置，不强制制作 9 张地图。

### 2.2 长局为什么不无聊

每 1–3 分钟玩家应至少遇到一种**新的可辨识局势**：敌人组合变化、孵化巢、精英挑战、战区事件、可选区域资源、独立奖励、构筑联动成型或 Boss 技能。不是每 2 分钟必须打开弹窗。

**关键决策**以“自然段落结束”呈现：
- 9 段遭遇中可设置约 **6–8 次重要奖励选择**（非每段都必须弹窗）；
- 每幕 1 次显著风险/报酬分岔；分岔决定下一段的敌种和奖励；
- 1–2 次精英/小 Boss 的掉落可以为合成组件或升级材料；
- 最终 Boss 开始后不再打开强化面板。

约 6–10 个高价值决策比 20 次零碎 +8% 点选更能保留 Build 成长感。

### 2.3 中断与长局可恢复性（长局必须新增的安全措施）

因为一局可能 20 分钟，手机 H5 切后台、误关页造成的损失会明显增大：

- 提供显式暂停和返回菜单能力；
- **每个幕/遭遇节点结束时自动保存“本局继续游玩快照”**（武器、临时等级、生命、进化、随机种子、战区、资源结算标识）；
- 回来后从**上个安全节点**恢复，不允许刷新刷候选卡、重复获取材料或重复杀精英领奖；
- 允许主动放弃本局，按已完成节点统一结算合法收益；
- Boss 战中不必保存每帧状态；意外退出可以从 Boss 前的安全节点恢复，且奖励/随机不会重复抽取；
- 局内恢复数据与局外永久存档分开管理；记录版本号、迁移/异常处理、结算幂等。

**如果做不到安全节点恢复，就不要贸然把标准局长拉到 20 分钟。**

## 3. 随机性设计：四层可控的变化

**同样的战场重复玩三局，应该有不同的路线、压力、奖励和 Build。**

| 随机层 | 具体随机内容 | 玩家如何看见差异 | 控制规则 |
|---|---|---|---|
| **A. 战场布局与路线** | 地图目标点/危险区位置、幕间分支、精英路线 | 本局往左拿武器组件，下局往右挑战精英 | 确保可到达、预告奖励；不出现封死道路 |
| **B. 敌方生态** | 当前战区特色虫种与可变组合、强化变种、阶段精英 | 同个场地，这局喷酸虫多、下局跃袭虫多 | 新手前段保底易辨识；所有技能有预警 |
| **C. 事件与风险收益** | 虫巢增援、军械空投、感染蔓延、能源异常 | 主动选择冒险拆巢拿资源，或绕开保命 | 最多一个重要事件同时发生；无随机必死 |
| **D. 构筑奖励** | 武器、模组、进化配方、协同融合奖励 | 这局电弧+冰霜，下局霰弹+燃烧 | 受控卡池：给玩家方向而非纯靠运气 |

### 3.1 不是“全部随机”，而是“随机 + 定向构筑”

每个重要奖励三选一，优先采用**1+1+1** 设计：
- **1 个协同候选**：与当前装备/标签/进化目标有关，确保可以持续构筑；
- **1 个不同方向候选**：有机会转型，避免每局早早锁死；
- **1 个通用候选**：防御、机动、经济或可变增益，提供兜底。

特殊稀有奖励可以调整，但不能三个都是无法生效的废卡。所有候选由合法池抽取；可在稀有度内保持随机，不能固定每次都给同一套最优牌。

### 3.2 可复现与公平
- 规划为每局生成 seed，保证同一版本+种子可以复现**路线、敌群大事件、卡池**；
- 地图随机点、战斗敌人随机与奖励随机采用分离流，避免多射一枪就完全改变后续卡池；
- 对危险事件设置预警和保护条件，避免随机事件同时夹击造成无解局；
- 可选精英路线收益更高，但失败后仍能获得已经完成部分的合理材料；没有失败就清零的赌博设计；
- 战区既有独特资源，也有随机微变；不能靠复制三张背景图声称三个战场完全不同。

## 4. 构筑系统：Build 要出现质变

### 4.1 当前缺口

M5.1 已有四种武器各自 Lv.1–5 和四条进化，但多数升级仍集中在伤害、攻速、弹丸数、跳链数。**武器之间缺少跨武器协同与实际合成机制**；一局只装四把枪但没有组件配合，长局后期容易变成单纯 DPS 比大小。

### 4.2 三层 Build 结构

| 层级 | 玩家获取 | 主要行为变化 |
|---|---|---|
| **武器槽（最多 4）** | 起始武器、重要奖励、战术卡 | 提供发射形态与攻击范围 |
| **武器模组（建议最多 2–3 个核心标签）** | 幕间卡、精英奖励或路线宝箱 | 附加冰霜、燃烧、穿透、连锁、电荷、部署协同标签 |
| **联动进化 / 流派核心（每局建议 1 个）** | 满足两类武器/标签 + 一次特殊配方选择 | 产生真正的新机制，例如爆炸连锁、燃烧传染、磁暴牵引 |

武器单独进化依旧存在（Lv.5 + 指定前置），**跨武器联动在此基础上更进一步**。建议同局有**一个主融合流派、可有 1–2 个辅助协同**，不默认所有武器都满进化和满融合。

### 4.3 首批四个可讲清楚的流派原型

| 流派名（暂定） | 核心组合 | 触发机制（必须不是单纯数值） | 明确代价/弱项 |
|---|---|---|---|
| **雷霜封锁** | 电弧 + 冰霜 + 连锁 | 被冻敌人受到电弧后，额外向附近目标传播减速和电荷 | 单体首领伤害不占优势 |
| **炼狱引爆** | 火焰 + 散射炮 + 爆裂模组 | 对已灼烧敌人造成霰弹命中时，引爆其一部分燃烧层，形成小范围爆炸 | 需要近距离/蓄积灼烧 |
| **磁轨风暴** | 电磁步枪 + 电弧 + 穿透 | 穿透弹在路径中留下电荷，下一次电弧攻击可沿路径扩散 | 需要方向/站位配合 |
| **壁垒熔炉** | 停步展开 + 装甲模组 + 火焰 | 展开时积蓄热能，撤离时释放一次防守冲击波，制造撤退空间 | 持续站桩有高风险、机动时输出较弱 |

所有协同都必须具备**清晰触发条件、变化后的命中规则/状态预算、失效条件**，不得只写“+200% 伤害”。此处是机制草案，数值在战斗模型原型后决定。

### 4.4 局内 XP 与决策的分工（避免升级弹窗）

- 每次 XP 升级：**自动选择已设定训练倾向**，升级武器等级或基础小属性；继续战斗，不中断。
- 幕间重大选择：玩家亲自选择**新增武器、模组、融合组件、路线与策略**；每次抉择带有不同代价。
- 进化：满足 Lv.5 + 必要前置自动触发，不再额外弹“是否升级”框；融合能力必须通过高价值奖励选择获得。
- 奖励依构筑标签定向推荐，但保留转型和意外发现机会。
- 不要为了取消小弹窗而把所有决策都自动化；**让玩家少点，但每次点得更重要**。

### 4.5 Build 的可达性验收

- 熟练玩家在完整局中应能完成 **至少一条武器进化 + 一个跨武器流派核心** 的合理概率，而非强制每局都完成；
- 至少两种不同成型流派能击败同一战区 Boss，不设定唯一 META；
- 三次同战区测试不应该总靠固定的一张“最强卡”通关；
- 每个流派有明显强项与弱项；不能简单按装备品质单向碾压；
- 流派核心奖励未完成时玩家仍有可用的普通构筑，不允许卡死成长。

## 5. 局外成长：失败也要给出下一步

### 5.1 选择战场与特定资源的动机

基于 [战区资源与装备 PRD](PRD_BATTLEFIELDS_EQUIPMENT.md)：
- **钢铁遗迹** → 军用合金 → 主武器框架与装甲；
- **感染巢穴** → 生体样本 → 枪械芯片、修复/耐久；
- **雷暴前哨** → 反应晶体 → 动力与能源模块；
- 所有战区产出**通用战备数据**，用于通用科技及机甲解锁。

**同一战区的每局随机事件和路线可变**；选战区锁定的是“主要资源/战斗主题”，不是某个固定关卡脚本。

### 5.2 失败仍有收获，但不能刷开局套利

- 按**已完成遭遇节点、实际击杀、可选目标完成、是否击败 Boss**结算；
- 失败拿走已获得且合法的战利品，Boss 通关给稀有但非唯一核心材料奖励；
- 若首幕阵亡但存活了一段合理时间，给予少量基础素材，使新手不会反复零收益；
- 主动秒退或故意短局快速刷新，不应产生远高于正常游戏的收益效率；
- 资源结算必须**一次性幂等保存**（战备与三类素材在同一事务）；不能按弹窗次数重复领；
- 结算页不只展示货币，需明确提示「距离下个装备强化还差 X 合金；钢铁遗迹是主产地」。

### 5.3 永久装备成长不是替代局内 Build
- 装备工坊主要提高**开局基础实力、容错和出击配置灵活性**，不能开局直接自带四个 Lv.5 武器；
- 科技研发提供少量通用加成与情报；机甲底盘改变站桩/机动取舍；
- 需要统一的总强化预算，避免装备 + 科技 + 机甲叠加无上限；
- 长期更大的奖励应来自**新初装方案、机甲差异、可选战区、挑战契约和可用新流派**，不是只有 +1%；
- 不增加体力、每日强制任务、广告装备、付费更强角色等阻挡重玩的设计。

### 5.4 存档与 15–20 分钟局长的关联
- **永久存档**：战区解锁、素材、研究、装备等级、机甲、成就；
- **当前局临时快照**：所选战区、战斗节点、当前 HP、局内武器等级/进化、奖励 RNG、临时 Buff；
- 两类数据分别保存，**中途恢复游戏不能再次结算同一场战利品**；
- 长局的恢复可靠性与奖励去重是优先于更多新 Boss 花样的前置条件。

## 6. 战区结构：同一基地里有不同出击目标

| 战区 | 玩法变体 | 主要资源 | 随机维度 | 强敌/终点 |
|---|---|---|---|---|
| 钢铁遗迹 | 工业通道、重甲压迫、可利用的暂时火力位置 | 合金 | 物资点位置、装甲虫组合、军械空投 | 机械防线里的虫巢统领 |
| 感染巢穴 | 菌毯侵蚀、孵化巢增援、近距离爆裂威胁 | 样本 | 巢穴节点位置、精英变体、破巢路线 | 异化母巢 |
| 雷暴前哨 | 周期性电网/能量区、远程与跃袭虫协作 | 晶体 | 安全区域变化、能源事件、精英掉落 | 暴走雷能主宰 |

**初版先提供 2 个战区 + 2 个有用途的资源 + 2 件可升级装备**，让“选战区 → 得材料 → 升装备”确实完整，不先上线三个空关卡。

## 7. 单局失败与结束界面

结算必须按以下认知顺序呈现：

1. **本局结果**：抵达第几幕/第几个遭遇节点，击杀、主要死因；
2. **Build 高光**：本局的主武器、武器进化和协同触发次数（尽量展示玩家自己造出了什么）；
3. **战利品**：战备数据、地区资源、精英或目标奖励，失败后已获得的资源清晰可见；
4. **成长机会**：当前是否足够升级一件装备；不足时指出哪种材料还缺多少；
5. **再来一把**：默认快速重开当前战区，同时可返回工坊或更换战区。

不要求结算后必须打开商店，不能通过漫长动画延迟再次出击。

## 8. 规划取舍与版本实现顺序

**不能同时上线“长局 + 多地图 + 全套装备 + 十几种融合”**。建议如下可玩的纵向切片：

| 版本（建议） | 应交付的完整可玩体验 | 先不做 |
|---|---|---|
| **M5.2** | XP 无打断、开局/幕间训练倾向，旧五波仍可对照 | 新资源、多战区、装备工坊 |
| **M6.0** | 一张战区升级为**三幕、15–20 分钟**，至少两个可选路线/事件、阶段重要奖励与安全节点恢复；**同版提供通用战备数据的失败结算和主武器框架首级可购买强化**，让长局死亡不白打 | 第二战区、地区专属素材、完整工坊 |
| **M6.1** | 两战区可选、不同主素材、**可消费的前两件装备工坊**、失败结算/永久存档 | 第三战区、全套科技树 |
| **M6.2** | 首批 2 个跨武器协同 Build + 战区事件/精英变化 + Boss 机制 | 四个融合全量/高阶商业化 |
| **M7.0** | 第三战区、晶体、另两件装备、有限科技研究、机甲解锁 | 无限研究树和全部高阶任务 |
| **M7.1** | 四协同完善、初始武器方案、挑战契约、成就与战区难度扩展 | 账号、多人、付费战力 |
| **M8** | 发行验证、品质/存档/渠道能力与可选商业化研究 | 先做付费道具再补留存 |

**M6.0 的安全快照、最小战备结算、首级可购买强化必须和长局结构同时交付**。不能先上线 20 分钟死亡零收益的战斗；M6.1 再完整扩展成两战区/两专属素材/两件装备的进阶闭环。

## 9. 产品验收——围绕三大体验，而不是功能数

| 体验目标 | 验收验证（方向性、非已观测数据） |
|---|---|
| 每局都新鲜 | 同一战区连续 3 次开局，遭遇节点/事件/重要奖励与 Build 形成明显差异；玩家能复述这些差异 |
| 失败也爽 | **M6.0 就必须具备失败后通用战备收益与一次可兑现的永久强化**；M6.1 才追加地区素材；结算不能重复领取 |
| Build 上头 | 一场完整局有合理机会获得 1 条武器进化 + 1 个显著协同，且协同有独立战斗行为/视觉反馈 |
| 连续割草 | 同一连续战斗段落因 XP 升级触发的强制弹窗数量 **0** |
| 长局不无聊 | 15–20 分钟有三幕明确压迫曲线与若干不同决策，不靠同样刷怪反复拖长 |
| 长局可靠 | 暂停/关闭/恢复能回到最近安全节点，没有重复材料结算或随机奖励刷新漏洞 |
| 局外可理解 | 玩家能在基地选择目标装备、看到所需资源及主产战区，并在 1–2 次点击返回出击 |
| 流派公平 | 不依赖唯一强力 Build、永久装备无上限数值，零强化玩家有入门战区通关路径 |

### 9.1 首轮玩家研究（不做性能限制）
首次重点测试：
- 长度上玩家什么时候想结束/什么时候仍意犹未尽；
- XP 自动升级后是否减少烦躁，但是否仍能控制构筑方向；
- 同一战区第二局与第一局的**具体可说出的差异**；
- 失败后是否能立即指出下一项可购买的装备；
- 两种不同协同流派是否被玩家主动尝试。

不把手机 FPS 当作产品阶段门槛；输入失效、存档丢失、卡死仍是技术 P0。

## 10. 重要待决策清单

**已确定：**
1. 产品三大支柱：每局新鲜、失败有成长、强力协同 Build。
2. 标准完整局允许拉长，**目标 15–20 分钟**，不是固定 4 分钟。
3. XP 自动小升级、不在战斗中弹升级卡；重要构筑决策放在自然阶段间隔。
4. 多战区资源有产地差异，并可兑换真实永久装备强化。
5. 局外科技、底盘和挑战保留；不以手机性能作为当前方向限制。

**后续试玩可调整：**
1. 每幕精确时间/遭遇数与重大选择频率；
2. 单局最理想的 1–2 条主融合流派，避免组合无限膨胀；
3. 装备永久强化效果与全局科技的叠加预算；
4. 各战区解锁与收益比、失败结算门槛；
5. 长局恢复节点粒度与分支随机种子规则。

**设计评判标准：玩家不仅要说“我打了很多虫”，还应该能说“这局随机到了不同的路线，我把火焰和霰弹凑成了炼狱引爆，虽然在最后一幕输了，但我带回的材料足够升级装甲，下次去雷暴前哨挑战电弧流。”**
