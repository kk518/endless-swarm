# M5.2 连续成长：发布说明与验收

> 2026-11-11 · 实现状态：已编码并通过自动化测试；真实手机交互仍需体验验收。  
> 历史注意：虽然里程碑号为 M5.2，但这项功能在已发布 M5.3 手机视野改动之后实施，二者同时保留。

## 玩家可见的变化

- **XP 升级不会再弹出三选一卡或暂停战斗**。击杀累计经验到达新等级时，角色照常移动与自动射击。
- **专精武器**：开局默认电磁步枪；每波结束的战术卡面板可重新选择下一波的优先升级武器。
- **训练倾向**：开局选择「火力/速攻/机动」，波末可调整。优先武器到 Lv.5 后自动升级其它已装备武器；全部已装备武器满级后，以所选倾向提高伤害、射速或移速。
- **自动进化**：已装备武器达到 Lv.5 并有指定战术蓝图时立即进化；如果先 Lv.5、后拿蓝图，在波末选卡成功时进化。不会额外消耗一个 XP 等级，也不会再出现专门的进化选择弹窗。
- **反馈可见**：经验条继续显示；HUD 状态提示当前专精和短暂自动升级/进化信息。
- **波末三选一完整保留**：每波结束仍由玩家决定新武器、配方与重要战术，选择时在同一面板设置下一波专精，不增加第二个弹窗。
- **五波/四武器/手机宽视野**：M5.1 和 M5.3 已有的战斗内容保留，不在这轮增加英雄和多战区。

## 自动升级规则

1. 对合法已装备专精武器升级，直到 Lv.5；
2. 然后按装备获得顺序升级其它已装备武器，最高 Lv.5；
3. 若全部达到上限，提升所选核心属性（伤害/射速每次 +8%，移速每次 +7%）；
4. 同一批 XP 跨级时，每一级即时兑现一次合法升级，不丢等级；
5. 当满足「Lv.5 + 指定波末配方」时自动进化，每把武器单局至多一次；
6. 新局重置 XP、等级、进化、专精；波末换专精只影响下一次升级方向，不回溯已升级内容。

## 验证

- `npm test`：自动成长、跨级、偏好回退、四武器进化、生命与现有战斗规则回归；
- `npm run build`：TypeScript 与 Vite 产物；
- 手机实测：下半屏虚拟摇杆在升级时不丢输入；整个波次不会出现 XP 模态；波末可切换专精并继续战斗；长按站桩与 M5.3 的敌群预警正常。
- 暂不把玩家实测、自由重开率或手机性能指标标记为已验证。

## 范围限制

当前自动分配采用**确定性武器优先级**，并不动态推断玩家的最优 Build。更复杂的多模组联动、英雄专属武器和 15–20 分钟长局属于后续版本，届时应增加幕间关键选择，而不是恢复逐级 XP 弹窗。
