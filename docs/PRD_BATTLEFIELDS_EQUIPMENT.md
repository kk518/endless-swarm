# 《无尽虫潮》战区选择、资源收集与局外装备强化 PRD

> 版本：PRD v1.0 · 2026-11-11 · **规划中，游戏尚未实现**  
> 产品阶段：**M6.1 两个资源战区 + 初级工坊**，M7.0 第三战区与高阶装备；M6.0 先建立三幕长局和安全节点恢复。  
> 关联：[产品总纲](PRD_V2.md) / [M5.2 无打断升级](PRD_M5_2_NONBLOCKING.md) / [局外科技/机甲 PRD](PRD_META_PROGRESSION.md) / [版本路线图](ROADMAP_M6_M8.md)

## 一、明确的产品目标

让玩家在局外**主动选择不同战场获取目标资源**，并把资源用于**永久升级机甲装备**。玩家的策略变成：

```text
返回基地（看见自己的装备目标）
    ↓
我想升级步枪框架，需要军用合金
    ↓
战区地图：选择「钢铁遗迹」 + 预计资源收益
    ↓
战斗：单指走位、自动射击、自动 XP 成长，不被升级弹窗打断
    ↓
结算：显示各类资源数量/来源；失败也有一定收获
    ↓
机甲工坊：消耗资源强化枪械、装甲、动力与核心模块
    ↓
装备效果在下一局生效；选择更困难/更高收益的战区
```

**关键差异**：不是「任意图打钱 → 永久科技加伤害」的单循环，而是让**战区选择服务于想升级哪件装备**；不同战区有不同环境威胁、刷怪组合、区域目标和核心资源。

## 二、系统分层（不要混淆）

| 层级 | 玩家决定什么 | 保存时间 | 产出/消耗 |
|---|---|---|---|
| **战区地图** | 下一局去哪个战场、挑战哪个威胁 | 解锁进度永久保存 | 战备数据 + 地区主资源 |
| **装备工坊** | 哪个装备槽强化、装什么配置 | 永久 | 合金/生体样本/反应晶体 + 战备数据 |
| **科技研发** | 全局轻量属性、战术情报 | 永久（M7） | 战备数据为主 |
| **机甲机库** | 不同底盘和初始武装方案 | 永久（M7） | 战备数据 + 特定资源，解锁后自由切换 |
| **战斗中 XP** | 依预设训练专精自动升级武器 | 只在当局 | XP，不消耗局外资源 |
| **波末战术卡** | 选择当局武器/特殊机制/进化前置 | 只在当局 | 选一张，不扣永久资源 |

**硬约束**：一局获得的临时武器 Lv.5 不代表工坊枪械 Lv.5。工坊强化只给新一局**基础装备参数**加成，不白送战斗内终极武器、局内卡牌或进化。

## 三、战区地图——首批三个不同战场

### 3.1 第一批战区

| 战区 | 核心资源 | 场景与敌方特色 | 玩家作出的独特选择 | 首次解锁 |
|---|---|---|---|---|
| **01 钢铁遗迹** | **军用合金** | 受损军械工厂、重甲虫、掩体缝隙、持续追击 | 绕开重甲正面，选择安全输出位置 | 默认解锁 |
| **02 感染巢穴** | **生体样本** | 有机菌毯、工虫与自爆虫、**可摧毁孵化巢** | 为获取样本冒险靠近并拆巢，还是先保命 | 默认解锁（初版允许自由二选一） |
| **03 雷暴前哨** | **反应晶体** | 失控电网、跳跃虫、远程喷酸/短时雷区 | 站桩输出 vs 躲避周期性危险区 | 在感染巢穴至少完成 3 波后解锁 |

均保留统一的单指移动、自动射击和五波框架；**玩法差异优先于更换背景颜色**。每个战区至少有一个可一眼辨认的环境规则和区域目标。

### 3.2 后续战区（暂不开发）

**04 母巢封锁区**：可选高难度战区，混合资源和独特首领阶段，作为已毕业装备玩家的挑战目标。**不新增第四种强制刷取材料**，避免资源种类泛滥。

### 3.3 战区配置数据（产品模型）

每个战区至少定义：

```text
zoneId / name / unlockRule / environment / enemyMix
recommendedPower（建议配置等级，仅提示，不限制进入）
primaryResource / rewardMultiplier
optionalObjective / objectiveReward / bossVariant
5-wave timing profile / stageResult
```

每次进入战区前，界面必须明确：
- 主产资源是什么、它可以用来强化哪类装备；
- 自己有多少资源、目标强化还差多少；
- 战区当前解锁状态、建议战斗强度和本战区独特威胁；
- 通关和失败可以得到多少资源（可显示区间，不能假装精确掉落）；
- 一键选择并出击，不用先切换数个中间面板。

### 3.4 战区间不是“低级图废弃，高级图全掉”

- **钢铁遗迹**在后期仍然是合金获取的最佳地点，不因为开放雷暴区就失去用途。
- **感染巢穴**专产生体样本，有不同装备配方持续需要。
- **雷暴前哨**以反应晶体为主，能给少量通用资源，但不会代替全部低级图。
- 玩家打不过某个战区，可以回到已解锁战区收集材料升级装备，不需要购买资源包或等待冷却。
- 不设计体力值、入场券、每日次数限制、扫荡券、广告才能领战利品。

## 四、资源体系与结算

### 4.1 四类账户，但只有三类地区素材

| 资源 | 主要产地 | 用途 | 设计备注 |
|---|---|---|---|
| **战备数据**（通用） | 所有战区 | 科技研发、机甲授权、装备升级的通用成本 | 延续 M7 原设定 |
| **军用合金** | 钢铁遗迹 | 主武器框架、装甲模块、部分机甲解锁 | 开局可获得 |
| **生体样本** | 感染巢穴 | 高级枪械芯片、生存模块、虫巢抗性 | 不要求玩家主动拾取小晶体 |
| **反应晶体** | 雷暴前哨 | 动力装置、能源核心、后期模块强化 | 第三个战区解锁后才作为必须材料 |

**控制复杂度**：初始只让玩家面对战备数据、合金、生体样本三项；反应晶体与第三个战区一起开放。不单设稀有货币、抽卡券、付费宝石、随机词条洗练石。

### 4.2 资源如何获得

- 每场游戏结算时按**实际完成波次数 + 有效击杀 + 战区目标完成情况**给予资源。
- 完整通关给予额外一次性奖励；中途阵亡也能获得与实际努力相称的资源。
- 在感染巢穴摧毁孵化巢可额外增加生体样本；未摧毁仍能正常通关，并获得基础样本。
- 不把收集资源变成需要手动点拾取物的强制操作；战斗内浮动目标是**可选高收益挑战**，资源领取在结算自动完成。
- 退出、手动放弃、刷新不允许重复结算刷材料。
- **同一场战斗的战备数据和全部素材在一次结算中原子更新**，避免只拿到合金而没拿到通用资源。

### 4.3 首轮拟定经济公式（测试参数，不是已平衡的数值）

> **注意：以下按旧五波给出的奖励样例仅供经济估算。正式的 M6.1 奖励必须随三幕九段长局、失败进度与各战区奖励结构重新标定；不能机械地把九段视为九波，避免货币通胀。**

所有资源数量为整数且不能为负：

```text
通用战备数据 = 按既有 M7 公式从时长/已通关波次/有效击杀/胜利计算
战区基础素材 = 4 + 4 × 已通关波次数
通关额外素材 = +12
战区可选目标完成 = +6 对应战区主素材
战区主素材 = 基础素材 + 通关额外 + 可选目标奖励
```

短时间放弃不发可刷取奖励；早期阵亡仍有基础回报（具体防刷门槛需结合失败时长实测）。

| 对局 | 波次已完成 | 可选目标 | 主素材示例 |
|---|---:|---|---:|
| 第一波失败但达到有效参与门槛 | 0 | 无 | 4 |
| 通过 2 波后失败 | 2 | 无 | 12 |
| 通过 3 波后失败 | 3 | 已拆目标 | 22 |
| 五波通关 | 5 | 无 | 36 |
| 五波通关且完成目标 | 5 | 是 | 42 |

**禁止按同一局的多个结束事件重复发放资源**。M7 战备数据公式和此处地区素材规则必须调用同一个结算事务。

### 4.4 资源用途与长期价值

- 合金主要投向主武器/装甲；
- 样本主要投向生存进阶/枪械芯片；
- 晶体主要投向动力/能源；
- 高级配方可以跨区组合（如武器 Lv.3 需要合金 + 样本），促使玩家**按目标主动选区**；
- 资源溢出不能无限兑换成更高阶数值，避免单区长期挂机刷成全装备满级；
- 一旦某战区已满足全部相关装备的当前材料需求，UI 应提示“这里的素材暂时充足”，而不是骗玩家继续刷。

## 五、装备工坊——可永久升级的四个槽位

### 5.1 工坊与战斗武器的关系

**工坊是军械框架强化，不是战斗内 4 把武器的自动解锁。** 在工坊升枪械不会让玩家第一秒同时装备全部武器，不会自动获得战术卡。它调整所有开局/局内武器的基础性能，战斗中仍靠抽卡获得额外武装、靠自动 XP 升级。

| 装备槽 | 主材料 | 永久提升方向 | 是否影响局内武器解锁 |
|---|---|---|---|
| **主武器框架** | 合金为主，进阶需样本 | 主武器基础伤害 / 枪械稳定性 | **否** |
| **装甲模块** | 合金 + 样本 | 受击容错、修复效果 | 否 |
| **动力推进器** | 晶体 + 合金 | 基础移动速度 / 展开切换稳定性 | 否 |
| **能源核心** | 晶体 + 样本 | 基础射速 / 能量续航 | 否 |

各装备槽独立升级到 **Lv.5**；强化等级永久保存，但始终允许零强化新手通关。M6 初版只上线**主武器框架 + 装甲模块**，防止三战区四资源一次全部堆到界面上。

### 5.2 永久强化效果（暂定上限）

| 槽位 | 每级效果（建议） | Lv.5 累计上限 | 约束 |
|---|---|---|---|
| 主武器框架 | 主武器基础伤害 +2.5% | +12.5% | 只对本局主武器有效，不将全部武器数值同步暴涨 |
| 装甲模块 | 回复/防护效率 +3% | +15% | 具体对哪种护甲效果生效需在战斗规则评审时确定；不得产生永久无敌 |
| 动力推进器 | 基础移速 +1.5% | +7.5% | 不破坏冲锋/自爆虫的躲避窗口 |
| 能源核心 | 所有武器基础射速 +1.5% | +7.5% | 不叠加无限时间减免 |

此处的**上限是产品约束**，不是已实现公式。与原 M7 研究树的同类属性需要整体预算：例如科技伤害 +6%、框架伤害 +12.5%，不能在叠加后误写成“只增加 12.5%”。

### 5.3 前两件装备的示例升级成本

| 装备等级 | 主武器框架（通用数据 + 合金 + 可选样本） | 装甲模块（通用数据 + 合金 + 可选样本） |
|---|---|---|
| Lv.0 → Lv.1 | 8 数据 + 12 合金 | 8 数据 + 12 合金 |
| Lv.1 → Lv.2 | 16 数据 + 20 合金 | 14 数据 + 18 合金 |
| Lv.2 → Lv.3 | 26 数据 + 28 合金 + 8 样本 | 24 数据 + 24 合金 + 8 样本 |
| Lv.3 → Lv.4 | 38 数据 + 36 合金 + 14 样本 | 34 数据 + 30 合金 + 14 样本 |
| Lv.4 → Lv.5 | 52 数据 + 48 合金 + 22 样本 | 48 数据 + 44 合金 + 22 样本 |

**平衡说明**：第一件强化理想情况下 1–2 次有效出击即可获得，前两级能够通过初始两战区取得。后三级要求两个战区配合，但不用取得 Boss 独占素材。费用在真实局长与收益分布后重新冻结。

### 5.4 实际装备决策

玩家在工坊看到：
- 当前装备等级、下一等级**真实效果**、所需素材和余额；
- 哪类资源不足，以及**一键返回能获得该资源的战区**；
- 可升级/缺材料/已满级状态；
- 装备强化只在**下一次出击**加载，当前战斗不应因打开另一个浏览器标签页而改变属性；
- 永久科技与装备强化拥有不同图标/色彩和独立数值来源，方便读懂增益。

### 5.5 装备 vs 科技——防止两个系统变成重复加伤害

- **装备工坊**：直接消耗**战区特定素材**，玩家可定向刷某个战场，偏重战斗装备；
- **科技研发**：消耗**通用战备数据**，提供少量全局强化和战术情报，不依赖特定战场素材；
- **机甲底盘**：选择不同基础移动/生命取舍，解锁不附带无限成长；
- M7 研发中的“精密枪管”与工坊“主武器框架”暂有同类伤害增益，必须通过**全局预算审查**，不能都叠加到无法平衡；
- 如果未来发现两个系统在 UI 和机制上高度重复，优先**合并科技枪管到装备工坊**，而不是增加更多重复的树。

## 六、界面信息架构

### 6.1 基地首页

```text
               星际军械库 / 战备基地
┌──────────────────────────────────────┐
│ 当前机甲：哨兵       资源：战备 / 合金 / 样本 / 晶体 │
│ 目标强化：主武器框架 Lv.2 → Lv.3                  │
│ 缺少：生体样本 ×8   [前往感染巢穴]              │
├──────────────────────────────────────┤
│ [战区地图]   [装备工坊]    [科技研发*]   [机甲机库*] │
├──────────────────────────────────────┤
│ [选择战场并出击]                                    │
└──────────────────────────────────────┘
* 后续 M7 开放，不在 M6.0 用假按钮占位
```

### 6.2 战区地图

采用三个可识别的战区卡/地图入口，每张卡优先展示：
- 战区名称、主要资源、环境危险、解锁条件；
- 我当前缺什么、该战区能补什么；
- 预计奖励与可选事件；
- “开始出击”明确按钮。

不把多个战区堆成虚假的开放世界大地图；可以先是一张战术星图上三个可选区域。

### 6.3 结算屏

一次显示四类信息：
1. 本局成就（到达第几波、是否击败 Boss、击杀）；
2. 主素材获得量；
3. 战备数据获得量；
4. “下一件装备还差 X 素材”与 `返回军械库`、`再次出击`。

结算与领取必须是同一事务，**无需再点一次“领取”**。

## 七、战区与装备的具体分期（与长局路线图统一）

本文件定义战区、素材和工坊。具体版本顺序以 [三大支柱与长局 PRD](PRD_ROGUELITE_CORE_LOOP.md) 及 [路线图 v2](ROADMAP_M6_M8.md) 为准。

### M6.0：三幕长局底座
- 先在现有一张可玩战场建立约三幕、九段遭遇的 15–20 分钟目标完整战斗局。
- 引入风险路线、幕间重大选择、事件和敌群变化；不能靠增加血量重复五波。
- 支持安全节点进度保存与恢复，重复加载不能重复拿奖励。
- 此阶段不引入地区素材/永久工坊，以便专注验证长局乐趣。

### M6.1：两个战区 + 两个素材 + 两个有用途的装备槽
- 钢铁遗迹（合金）与感染巢穴（生体样本）可选择；两者有不同敌方生态/环境。
- 同期引入通用战备数据、两种地区素材、战后结算与永久存档。
- 主武器框架和装甲模块至少开放前两级，素材可以直接被消费。
- 失败按有效遭遇进度取得一定资源；工坊可以跳转缺料战区。
- 不要求雷暴晶体才能解锁雷暴产地，不产生经济死锁。

### M6.2：两套跨武器 Build 与战场随机
- 首批雷霜封锁、炼狱引爆协同，重点是机制质变。
- 增加可辨识的事件/精英/路线变化，不新增第三种强制资源。

### M7.0：第三战区和完整永久装备成长
- 雷暴前哨（反应晶体）和推进器、能源核心开放，强化研究/机甲系统。
- 工坊四个槽位升到 Lv.5；科技和装备的总数值预算必须合并评审。

### M7.1：长期挑战
- 新初始武装、挑战契约、成就与更多协同，不再靠无限装备等级驱动复玩。

## 八、经济平衡与反刷设计

1. 按“完成波次 + 实际击杀 + 目标完成”给资源，不能仅依靠瞬间进入退出刷钱。
2. 首次失败后仍有收获（达到有效参与门槛）。
3. 不做随机付费素材包、体力门槛或时间加速付费。
4. 任何一笔装备购买必须原子地：检查足额 → 扣多种素材 → 强化装备等级 → 保存。
5. 两个标签页同时玩时必须防止存档互相覆盖、双发奖励和旧余额覆盖新余额。
6. 高级装备升级成本随等级递增，但**不得**导致玩家刷十几局同一战区毫无变化；应让玩家在每 2–4 局看到一个明确可达的目标变化（方向性目标，需实测）。
7. 资源收益与解锁不能设计成死循环：无法获得某素材前，玩家不能被要求先使用该素材才能解锁产地。
8. 资源不足提示必须指向**当前可进入**的产地，不诱导用户点击尚未开放的区域。

## 九、可执行验收

| ID | 条件 |
|---|---|
| ZONE-01 | 初始两战区可选择，第三战区解锁条件明确，重新启动保留地图解锁 |
| ZONE-02 | 每个战区至少一项真实的敌方/环境差异，不能只换背景色 |
| ZONE-03 | 每种资源都有明确产地与可消费装备，选区能有效追踪缺失素材 |
| ZONE-04 | 不同战区正常结束、失败/胜利/重开和后台恢复均安全完成一次结算 |
| ZONE-05 | 战备数据与地区素材在一个事务中结算，重复结束/刷新不能多领 |
| ZONE-06 | 初期装备强化可在 1–2 次有效出击后购买，成本/收益可人工复算 |
| ZONE-07 | 工坊强化上限明确，购入后下一局真实生效；局内升级另行清空 |
| ZONE-08 | 新战区难度可以靠走位和当局构筑克服，不需要充值或无限永久升级 |
| ZONE-09 | 虫巢可被自动攻击，玩家有绕开/破坏的合理选择，奖励与预警清楚 |
| ZONE-10 | 素材与装备进度在 H5 本地可靠存储，禁用存储时显式告知失败 |
| ZONE-11 | Android/iPhone 可单手完成战区选择→战斗→结算→强化→再出击；**本阶段不以 FPS 数值做立项闸门** |
| ZONE-12 | 关键规则自动测试通过；真实用户能说明“为什么选择这个战场” |
| ZONE-13 | 已升级装备不让四武器自动全部解锁、不绕过战术卡和进化条件 |
| ZONE-14 | 可以从工坊直接返回当前缺少材料的战区，无空白资源闭环 |

## 十、明确的非目标

- 不设计联网世界地图、多个可移动角色组队、手动射击；
- 不增加装甲装备随机品质、抽卡掉装备、数十个装备槽；
- 不增加需要连续操作的采矿小游戏；
- 不靠任务列表强制玩家每天上一次线；
- 不做无上限挂机收入、时限体力及广告复活；
- 不把手机 FPS 当作当前产品迭代的主要驱动；但仍应避免卡死、数据损坏和无法操作。
