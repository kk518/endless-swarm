# M5.3 手机虫潮可见性（实现说明）

> 实现版本：M5.3 · 2026-11-11 · 变更范围：手机竖屏视野、基础自动索敌、敌群入场；**不包含 M5.2 无打断 XP、英雄、15–20 分钟长局。**

## 背景

原逻辑画面固定宽 450，左右单边只有 225 世界单位。步枪基础射程 360；普通虫群大多在距玩家 325–463 单位处生成，因此部分虫族在屏幕外被击杀，玩家只能看到击杀数上涨，不能看到虫潮靠近。

## 实现

1. **手机世界宽扩到 600 单位**：`src/main.ts` 在竖屏移动设备创建 600 单位宽画布、按屏幕比例计算高；桌面仍为 450。此方案从视野效果上等同于约 0.75 倍世界缩放。
2. **HUD 单独缩放**：`GameScene` 建立 HUD Container，保持 450 单位设计空间，使用 `scale.width / 450` 补偿；摇杆输入坐标除以 HUD 缩放倍率，文字/血条/摇杆在物理手机上的显示尺寸基本不变。
3. **普通武器优先锁屏内敌人**：对可见相机矩形增加 64 世界单位的读图边距，普通武器仅主动瞄准已进入该范围的敌人；步枪此前锁定的目标最多保留 250ms 离屏宽限，避免频繁切换。
4. **入场预警**：手机虫群出生点优先落在相机边缘内侧，保持与玩家的安全间距；0.7 秒标记入场，Boss 1.05 秒，之后才生成可攻击的虫体。这样虫群有约 0.4–0.6 秒的可见接近时间（随怪物速度、方向而变化），并非以增加生命或无敌机制硬拖时间。
5. **独立规则单测**：`src/game/visibility.ts` 提供屏内区域和边缘出生点纯逻辑；测试覆盖视野扩容、非法出生点、入场计时、HUD 坐标对应关系。

## 边界与保留机制

- 实际伤害、敌人生命、卡牌、进化、武器射程、升级弹窗与五波规则保持 M5.1 不变。
- 已射出的穿透弹、爆炸和电弧连锁可以越过画面边缘伤害敌人；**限制的是普通武器的初始自动索敌，而不是给所有屏外虫子加无敌**。
- 当玩家在地图边缘、画面内无法找到既安全又可见的敌人出场点时，拒绝此次出生，避免贴脸刷怪；可能导致边界处敌量略少，后续可进一步设计相机边缘偏置。
- 本版尚没有英雄级狙击武器；未来可为其设计有明确提示的远距离离屏索敌特例。
- **真机主观验收尚未执行**：应观察机甲人形轮廓是否清楚、虫子是否可见地接近、摇杆是否跟手、后期是否出现异常低敌量。

## 验收

- 自动化：`npm test`、`npm run build` 与 GitHub CI 成功。
- 手动：iPhone/Android 竖屏体验、左右滑动摇杆、变更浏览器地址栏高度/旋转页面、靠近世界边缘、Boss/精英入场。
- 主要体验判断：玩家是否能看见虫群涌入并被火力清场，而不是虫族未出现就被击杀。
