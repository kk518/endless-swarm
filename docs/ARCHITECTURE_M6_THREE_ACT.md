## 1. 本轮完成范围

围绕 M6.0a 的 Campaign→Act→Encounter 状态机，把已有四武器五波原型扩展成**可选择的三幕九遭遇实验模式**。

| 项目 | 本次实现 | 当前限制 |
|---|---|---|
| 入口 | 出击前可选「五波封锁」或「三幕远征（实验）」 | 实验模式不会成为默认线上玩法 |
| 阶段调度 | 3 幕 × 3 遭遇、980s 计划战斗时长，按配置切换 | 仍用现有 5 档敌群模板与原地形 |
| 战术奖励 | 六次阶段结束三选一，XP 小升级始终自动 | 沿用现有 22 卡，未上线英雄改造/史诗融合 |
| 风险路线 | 两个阶段出现独立二选一；真正改变 HP、持续伤害和下一段刷怪压力 | 路线暂不改变地图地形/材料掉落 |
| 终局 | 第九段 Boss 击杀胜利、超时失败；旧五波第 5 段仍通关 | Boss 还是现有虫巢巨兽，没有二阶段 |
| UI | 关卡标题、路线抉择卡、安全/高危颜色、出击模式提示 | 暂未制作完整星图、战区选择、工坊 |
| 测试 | 原有测试 + 路线合法性/九段流程/界面接线测试 | 仍需真实手机长局试玩 |

新增的配置均基于通用关卡定义，不要求以后给每张新地图重新复制 `GameScene`。

## 2. 游戏流程

```text
出击前选择
  ├── 五波封锁（原版）：4 次战术奖励 → 第五波 Boss
  └── 三幕远征（实验）：
      第一幕：降落区（卡）→ 突破防线（风险路线）→ 先遣精英（卡）
      第二幕：污染压制（卡）→ 巢穴分岔（风险路线）→ 核心精英（卡）
      第三幕：虫群集结（卡）→ 终局整备（卡）→ 虫巢统领（Boss）
```

**共 6 次三选一卡牌 + 2 次路线选择**，不含开局选择；所有决定都在遭遇结束、安全暂停时做。战斗中没有经验升级弹窗。

九段原型计时（毫秒）：
`[100000, 105000, 110000, 105000, 110000, 110000, 105000, 95000, 140000]`，总和 `980000ms`（16 分 20 秒），不包括玩家在菜单做决策的时间。后续要结合真实试玩调整长度、XP 成长和生存难度。

## 3. 风险路线的真实效果

两次路线分岔的 **安全选择** 均为：回复至多 2 点装甲，不额外增加敌人刷新速度，也没有伤害奖励。

**高危选择** 均为：立即损失 1 点装甲（至少保留 1 HP），本局伤害乘数 ×1.15，下一**一个**遭遇敌群出生间隔缩短（第一处分岔刷新速度 +25%，第二处 +30%）。高危强化能跨阶段持续，但高危敌群压力不会永久叠加。

- 玩家只剩 1 HP 时，高危选项从 UI 候选池中移除，不能在安全菜单中被路线点击致死；
- 选项经过实际合法性过滤，重复点击不能重复修复/叠火力/推进阶段；
- 选择后下一阶段开始时清空前一段敌人/弹幕，并重置本段战斗计时与炮台冷却；下一段结束后清除该次压力增量；
- 高危加成仅影响**本局 RunBuild.damage**，不会偷偷保存成局外科技；实验版没有地区资源和装备工坊。

## 4. 为什么不直接上线长局

**当前三幕远征能按规则玩，但不是长期 Roguelite 的完整交付。** 玩家投入十几分钟后失败，除了原有击杀记录，尚不能获取规划中的资源和局外装备成长；同时缺少页面关闭后的**可恢复中断存档**。

因此主玩法仍默认五波原型；三幕远征必须由玩家在开发分支里主动选择，页面上明确提示实验性质。不要直接把此分支发布到线上并宣传完整长局。

## 5. 当前扩展边界

- `campaignDirector.ts`：每个 Encounter 的决策类型 `card | route | none`，路线必须附有合法选项，非路线不能附；未来可扩 `event` 但必须提供对等 UI 与测试。
- `routeDecisions.ts`：路线选项和纯规则计算；不能用 UI 自行篡改 RunBuild 或 HP。
- `GameScene.ts`：在安全阶段按配置派发 `swarm:reward` 或 `swarm:route`，调用统一推进函数；Stage 奖励不可重复提交。
- `main.ts` / `index.html`：显示玩家选择；路线只占一个阶段决策，不额外出现第二层卡牌菜单。
- `contentCatalog.ts`、`weaponRuntime.ts`、`heroRuntime.ts`：仍保留后续英雄与枪械的稳定扩展位置，当前没有新增任何未实现的英雄/攻击驱动。

## 7. 接下来应优先完成 M6.0c

不再追加英雄、武器或更多弹窗。优先实现：
1. **安全节点存档**：只在关卡选择界面/阶段边界自动保存。包含战斗配置、英雄、武器/自动成长、HP、时间、关卡进度、路线结果及随机流游标；经 schema 校验和版本兼容后再支持恢复；
2. **一次性结算与失败收益**：有效对局获通用战备，死亡和胜利都能看到真实收获，避免重复发奖；
3. **最小局外装备成长**：基地能花战备购买至少一项受限的永久装备强化，不依赖新英雄和新战区；
4. 真机验证，再决定是否把三幕远征升级为正式默认模式。

**边界声明**：本次只是长局战斗主循环和路线选择的最小可运行框架。M6.0c 完成之前，不合并/上线为完整长局。
