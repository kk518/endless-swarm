# M4 美术规范 · IRON VEIL / 铁幕防线

> 设计主轴：**工业秩序对抗生物失控**。不是给所有物件加青色辉光，而是为两个阵营使用彼此冲突的形体、材料与运动节奏。

## 形体约束

| 侧别 | 轮廓/局部语言 | 明暗/材质 | 点缀 |
|---|---|---|---|
| 人类装甲 | 斜切矩形、硬边、对称分件、支架 | 枪灰、冷白磨损线、深色缝隙 | 少量琥珀橙警示标记，胸核冷青 |
| 虫巢 | 弯曲钩爪、裂口、鼓胀腺体、不对称背甲 | 暗紫黑、淤红、骨白边脊与低饱和肉色 | 自爆器官玫红，喷酸囊脏绿 |
| 场景 | 工业舱盖、检修线、旧安全警戒标志、锈斑 | 石墨蓝黑+灰绿 | 侵蚀菌纹从外围缓慢涌入 |

**保持高亮区域克制**。主角光点与自爆器官属于信息节点；其余位置不做通体霓虹。

## 六种虫族剪影

- **工虫 crawler**：窄三角头、钳形口器、短腹、向外张开的多足
- **跃袭虫 leaper**：超长镰刀前肢，细长脊柱，强辨识方向
- **装甲虫 armored**：宽背甲、前厚后窄，纵向护盾裂缝与低位置感官缝
- **喷酸虫 spitter**：鼓胀发光腺体、脆弱细腿、外露喷管
- **自爆虫 bomber**：外露易爆囊，肋壳裂缝、粉红红核心，爆炸范围清晰预警
- **首领 broodlord**：分裂厚甲、尖角冠、延伸脊髓与巨大不对称侧钩
- **精英变异**：保留原虫种剪影，使用厚边框脉冲和发亮甲纹识别，绝不拿“全身金色换色”取代新轮廓

## 层次与光照

采用俯视 **2.5D 手绘矢量层次**，不使用实时 3D 模型。每个单位具备：
1. 偏移的深色脚下投影（锚定地面）
2. 深色结构与机体主色
3. 上沿和骨缝高光，底部保持低亮度
4. 极少量阵营专属发光区域
5. 冲击时短时色彩闪白、死亡后地面留低饱和痕迹

静态地表独立 Graphics 一次绘制，持续掉落物、虫族和火力效果沿用对象预算；低端手机不引入复杂实时阴影或后处理 Shader。

## HUD 与战术模块卡

- 矩形切角、工业警示色条、序号、参数而不是全圆角浮动卡片
- 正文优先可读性；提示以琥珀色强调，装甲及能量以低饱和青色表示
- 选卡界面为军用模块授权台；每张卡保留分类、效果、明确的序号
- 小屏和短屏需要可滚动、可聚焦，不能为装饰牺牲可玩性

## 视觉验收

- 手机屏幕上不阅读文字也能区分五类常规虫及首领
- 升级卡可读，玩家生命/波次/剩余时间优先于美术
- 站桩时能直接看到装甲支架由未部署到展开
- 视觉特效不遮挡自爆危险区和首领血条
- 60FPS 目标；禁用每帧重新生成纹理，严格约束大量单位绘制成本

本次所有纹理由 `src/game/Art.ts` 使用 Phaser Graphics 同步绘制生成；`artStyle.ts` 绑定虫种与调色板，新增的资源映射有 Node 规则测试。
