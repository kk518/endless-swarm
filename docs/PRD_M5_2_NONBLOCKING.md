# 《无尽虫潮》M5.2 PRD：无打断成长与波末决策

> 产品需求版本 v1.0 · 2026-11-11 · **规划，未开发**  
> 重要反馈来源：玩家明确表示“升级频繁触发弹窗影响体验”，此条作为**已确认的体验问题**，不再等待十人实验来确定是否需要处理。  
> 对应 [产品总纲](PRD_V2.md) · [战区与装备 PRD](PRD_BATTLEFIELDS_EQUIPMENT.md)

## 1. 需求结论

**取消所有战斗过程中的升级弹窗，升级不能中断连续割草。** 仍保留战斗中的 XP、四武器 Lv.1–5、四条进化和波后卡牌构筑，让操作维持单指移动与自动射击。

从「XP 满 → 停止游戏 → 三选一 → 恢复」变更为：

```text
出击前选择【训练专精：主武器 + 战斗倾向】
  ↓
战斗期间击杀自动得 XP → 升级自动结算
  ↓
自动按专精升级已装备武器 / 触发基础属性成长
  ↓
满足 Lv.5 + 战术材料 → 自动完成进化，不暂停
  ↓
每波结束只出现【一个战术整备界面】
    ├ 现有三选一波后战术卡
    └ 可选切换下波训练专精（同一界面，无额外弹窗）
  ↓
直接进入下一波
```

这版要求**一个连续战斗波次 0 次强制选卡弹窗**，而不是把弹窗换成其他名称继续暂停。

## 2. 用户目标与设计原则

1. 玩家要能连续移动/开火/消灭虫海而不被频繁暂停。
2. 自动升级不代表玩家完全失去构筑权：**玩家在开局和波末决定方向**，战斗中按方向自动执行。
3. XP 获得、升级和进化要有可见反馈，但反馈只能是非阻塞提示（短文字、能量条、轻量音效、武器造型变化）。
4. 不引入战斗中的“点击加点”“长按确认”“二次摇杆”或操作密集型功能。
5. 战斗升级只影响本局；局外装备和科技是另一个独立系统。

## 3. 具体交互设计

### 3.1 开局：一次性训练方案

首版只提供一个紧凑选择区域，不增加单独启动向导；默认已选好，不做额外强制点击。

- **优先武器**：默认电磁步枪；可选当前初始武器。战斗时只能在已经装备的武器中选择专精，不能凭空解锁新武器。
- **训练倾向**：三个自动加成类型，默认「火力」：
  - 火力：多出的升级点自动转化为全武器伤害成长；
  - 速攻：多出的升级点自动转化为攻击频率成长；
  - 机动：多出的升级点自动转化为移动速度成长。
- 主屏用简短信息表明“升级自动进行，可在波后调整”。

**默认无障碍路径**：玩家不做任何设置，直接进入游戏，默认主武器为步枪、倾向为火力。

### 3.2 战斗中：自动升级分配

- 每次击杀依照原 XP 规则计算经验和等级，不得丢失溢出经验。
- 每次提升 Pilot Lv 时产生 **1 次自动升级结算**，该结算不能暂停时钟、敌人、输入或攻击。
- **分配优先顺序**：
  1. 若专精武器已装备且等级 < Lv.5，优先将其提升一级；
  2. 专精武器已 Lv.5 时，尝试按出击武器装配顺序升级其它已装备的武器（最高 Lv.5）；
  3. 所有已装备武器已 Lv.5，才按照训练倾向给予轻量核心成长（伤害 +8% / 射速 +8% / 移速 +7%）。
- 若新武器在波末解锁，新武器从 Lv.2 安装校准开始；下一波自动成为可升级候选。
- 自动获得的升级**不得突破武器 5 级、角色 25 级和现有核心属性数值护栏**。
- 当主武器未解锁或被切换成非法武器时，回退到首个已装备武器，不产生空升级。
- 初始拥有的步枪仍是 Lv.1；波间解锁的新武器仍 Lv.2。

**具体选择可调**：初版不给每个 XP 等级另开复杂权重系统，先使用确定性的升级优先级。之后如果构筑单一，再引入「优先级列表」而非战斗弹窗。

### 3.3 进化：满足条件即自动触发

- 已装备武器达到 Lv.5 且已拥有指定进化材料时，自动进化。
- 如果先有前置战术卡，升级到 Lv.5 时自动进化；如果先 Lv.5，波后拿到前置卡，则**在下一波开始时自动进化**。
- 进化不再消耗一个必须弹出的 XP 三选一名额；代价已经由**投资 4 次武器升级 + 在波末选择指定战术卡**体现。
- 为防止进化变成“无选择的廉价强化”，必要时调整 Lv.5 提升成本、战术卡供给或进化强度，**不通过重新插入强制弹窗解决**。
- 单局每把武器最多进化一次，不重复结算、不发 XP、不新增进化资源。
- 只显示 1 秒左右「轨道歼灭炮上线」类非阻塞提示，不覆盖敌方危险预警。

### 3.4 波末：只有一个战术整备面板

- 第 1–4 波仍各有一次波末三选一战术卡，保留“玩家作出重要选择”的核心节奏。
- 战术面板里同时展示当前专精武器及其等级、下一波训练倾向。
- 玩家可在同一面板里改变专精，不额外打开第二层训练弹窗。
- 只需**选一张卡**便可开始下一波；若未修改专精，则沿用上波设置。
- 卡牌仍须来自合法候选池。进化材料推荐规则沿用 M5.1，并对新自动升级节奏进行调参。
- Boss 波内不弹出升级选卡，也不在 Boss 最后一击之后补发一组训练弹窗。

### 3.5 HUD 与非阻塞反馈

- XP 条、Pilot Lv 和武器等级继续保留；满级只显示 MAX。
- 自动升级时在 HUD 上方短暂提示「电弧线圈 Lv.4」/「火力校准 +8%」。
- 同一帧多次升级时将提示合并为「本次提升 X 级」，不连发大量占屏消息。
- 危险预警和 Boss 机制具有**更高显示优先级**，升级提示绝不能遮挡它们。
- 开局训练专精有可读的小字和默认值；短屏下不将 HUD 扩展为第二操作面板。

## 4. 设计取舍与备选方案

| 方案 | 优点 | 缺点 | 决策 |
|---|---|---|---|
| 每级仍弹出三选一 | 决策最多 | 已确认打断战斗 | **否决** |
| 把多次升级全部堆到波末逐个领取 | 战斗不中断 | 波末容易一次点十多次 | **否决** |
| 局内自动升级、波末决定构筑和专精 | 连续射击、保留方向性、可预测 | 需要解释自动分配规则，极端构筑有固定序列 | **M5.2 默认方案** |
| 局内可选手动开面板 | 自由度高 | 一手移动操作中增加交互与误触 | 后续研究，不作为 P0 |

## 5. 成功标准与验收

| ID | 验收条件 |
|---|---|
| FLOW-01 | 玩家从每波开始到结束之间 **0 次由 XP 升级强制弹出的模态面板** |
| FLOW-02 | 所有 XP 增长、升级属性、敌人时间继续正常模拟，不出现短暂停顿或积压选卡 |
| FLOW-03 | 默认设置无需额外操作；单手移动/自动攻击/站桩火力展开不回归 |
| FLOW-04 | 武器仅在已装备时自动升级，Lv.5 封顶，溢出转给其它已装备武器/核心倾向 |
| FLOW-05 | 两种不同选择的训练专精在相同成长条件下形成不同的武器等级顺序 |
| FLOW-06 | 进化在满足 Lv.5 + 战术配方后自动触发且只触发一次；无弹窗 |
| FLOW-07 | 第 1–4 波仍仅有一个波末三选一战术整备界面，不叠加第二个升级队列 |
| FLOW-08 | 危险预警优先于升级提示，视觉上能辨识升级已发生 |
| FLOW-09 | 第 5 波、死亡、浏览器后台、重开不能制造遗留升级状态或重复应用奖励 |
| FLOW-10 | 游戏结束时仍显示等级、装备等级与进化数量，方便验证 |
| FLOW-11 | 单元测试覆盖 XP 跨级、合法分配、战术切换、自动进化、单局重置 |
| FLOW-12 | 真人试玩明确报告“选卡打断减轻”；实际感受要优于当前 M5.1 基线 |

## 6. 与其他需求的依赖

- M6 多战场将复用此**不中断升级**节奏，不为每个战区设计另一个升级 UI。
- M7 装备强化在**战场外**通过基地完成，不影响战斗中自动 XP 的归属。
- M6/M7 的资源掉落在战斗后统一结算；战斗中不产生“资源掉了请点击收取”的强制弹窗。

## 7. 迭代顺序（本轮只做 PRD）

1. 确认本需求，记录升级弹窗为已确认体验痛点。
2. 与现有 M5.1 差异对表：暂停/升级队列/进化触发/UI/结算。
3. 将需求拆成自动成长领域规则、波末整备 UI、回归与体验验收工作包。
4. 取得一次小范围体验对比后，再决定是否实现更复杂的训练路线。
