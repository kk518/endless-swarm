# 《无尽虫潮》M5 产品需求文档：战地进化

> 文档版本：v1.0 · 日期：2026-11-11 · 状态：开发基线 · 优先级：P0  
> 关联：[原始 MVP PRD](./PRD.md) / [技术设计](./TECH_DESIGN.md)  
> 游戏：Endless Swarm · 移动端竖屏 H5 · Phaser 3 + TypeScript  
> 适用范围：M5.0 核心成长闭环；M5.1–M5.2 为规划范围，明确不作为本次交付承诺。

## 1. 为什么要做 M5

### 1.1 当前产品状态
游戏当前具备单指移动和自动攻击、站桩火力展开、五波虫潮、四种武器、22 张强化卡、精英怪、补给与首领。M4/M4.1 完成阵营视觉、武器挂载与战斗特效。当前单局只有四次波间三选一，既要拿到新武器又要做属性和机制强化，玩家往往到尾声才凑齐武器，缺少持续成长的期待。

### 1.2 目标体验
**每 20–40 秒左右出现一次有意义的成长节点**（数值为调参目标，非保证）；让玩家在同一局里经历「初始步枪 → 多武器阵列 → 关键卡牌成型 → 武器进化 → Boss 验证」的反馈曲线。升级不是单纯叠数字：应该改变弹丸数量、穿透、跳链、持续火力或战术定位。

### 1.3 本阶段衡量指标（待真实用户试玩）
| 维度 | M5 初步目标 | 测量方式 |
|---|---|---|
| 早期成长 | 第一波结束前至少有一次局内升级的合理机会 | 正常击杀模拟与真机观察 |
| 中期成长 | 第三波前至少能形成一个独立的武器等级倾向 | 玩家回放与武器进度记录 |
| 进化可达性 | 熟练玩家能够在 Boss 前达成一条进化路线 | 可复现构筑与随机种子测试 |
| 选择清晰 | 玩家能区分「经验升级」与「波后战术卡」 | 未看说明的试玩问答 |
| 重复游玩 | 玩家有理由改变下一局的武器与卡牌选择 | 试玩访谈 |
| 性能底线 | 新机制不明显降低中端机高压场景帧率；目标 60FPS/底线 30FPS | 真机记录 |

**不以纯功能数量作为成功标准**。如果经验弹出过于频繁导致割裂感，优先调节成长节奏。

## 2. 定位和不可破坏的约束
- 仍是手机竖屏、单指移动、自动瞄准、移动时开火、停步火力展开的 Roguelite。
- 仍有五波、第三波自爆虫、精英补给和第五波 Boss；本次不重写敌人 AI/视觉特效。
- **经验获得不需要玩家拾取额外晶体**：每次击杀直接计入战术经验，减少手机上的走位干扰、屏幕物件和掉帧。
- 所有成长仅限当局；重开时清零。保留本地最高击杀数，无用户账户、联网、内购或广告。
- 任何成长弹窗时战斗逻辑完全停止：不前进冷却、伤害、波次时间、虫群生成、连杀时间。
- 经验弹窗和波末抽卡必须互斥，不允许同时出现。
- 不因升级而打断手势留下持续移动：进入选择时释放浮动摇杆状态。

## 3. M5.0 游戏内循环

1. 击杀敌人 → 直接获得经验（HUD 有实时等级/进度条）。
2. 达到当前经验阈值 → 等级 +1，产生一个三选一的**战斗升级**机会。
3. 暂停世界 → 选择武器等级强化、通用小型增益或满足条件的进化 → 立即应用 → 继续原波次。
4. 若一次获得大量经验跨多级，升级机会排队逐一兑现；未选择前不自动取消。
5. 第 1–4 波结束仍免费获得一次**波后战术模块**三选一（大幅、稀有加成或新武器）。
6. 新武器从一级开始可参与经验升级；由波后新增的武器可获得一次安装校准奖励（直接达到 2 级）。
7. 第五波击败首领成功，结算展示经验等级、四种武器等级和进化状态；死亡、超时也显示当局成长。

## 4. 经验来源和等级节奏

### 4.1 经验数值（可配置）
| 击杀 | 经验 |
|---|---:|
| 普通工虫/跃袭虫/装甲虫/喷酸虫 | +1 |
| 自爆虫（被击杀而非自行爆炸） | +2 |
| 精英虫 | 基础经验 +4 |
| 首领 | +12（主要用于结算记录，不强求胜利后弹出升级界面） |
| 爆炸连锁直接击杀 | 按实际死亡的每只虫独立授予经验 |
| 自爆虫自行起爆 / 敌人波末清退 | +0 |

### 4.2 等级算法
- 初始等级 Lv.1，经验 0。
- 升至下一级需要：`8 + 3 * (当前等级 - 1) + 2 * max(0, 当前等级 - 7)` 点经验（整数）。
- Lv.1→2 8XP，Lv.2→3 11XP，Lv.3→4 14XP；后续递增。
- 等级上限暂定 Lv.25（避免无限增长）；满级不再产生奖励，条显示 MAX。
- 跨级经验结算需要携带溢出经验，不丢弃，不重复计分，不制造负值。
- 本阶段不启用击杀经验倍率、不启用经验道具，以便观察自然进度。

### 4.3 升级弹窗
- 标题包含等级：「战术升级 / LV. X」；字幕标记「当前战斗暂停」。
- 默认展示恰好三个不重复、可生效选项。因极端构筑无法组成三选项时，使用无上限的通用升级项兜底。
- 选项分为武器等级、通用轻量增强、进化。
- 可升级武器必须已装备且未满 5 级；未装备武器不出现在局内升级卡池。
- 初期选项**至少包含一项已装备武器等级升级**，让玩家理解真正的武器成长。
- 一旦满足武器进化条件，保证进化选项出现，避免随机机会错过关键时刻。
- 玩家点击后立即生效并解除暂停，所有按钮可被触控和键盘聚焦。
- 同一段击杀触发跨级时逐个弹出，UI 使用队列，不递归爆栈。

## 5. 武器等级和进化

### 5.1 所有武器 1–5 级
- 未装备武器无等级进度；获得时为 Lv.1，至多升级到 Lv.5。
- 增强效果必须真实驱动战斗逻辑；HUD/选择页显示实际等级。
- 推荐初值：每升一级武器基础伤害 +16%，攻击间隔缩短 6%，可叠加至四次；单独乘以原有通用卡牌和姿态倍率。
- **差异化机制**：
  - 电磁步枪：等级带来更稳定的高频穿透输出；
  - 散射炮：Lv.3 与 Lv.5 各增加两枚弹丸，近身弹幕覆盖更宽但仍受弹数上限；
  - 电弧线圈：Lv.3 与 Lv.5 分别增加一次跳链目标，最多六段；
  - 火焰喷射器：随等级扩大攻击射程，伤害持续触发，避免每帧无限连锁。

### 5.2 首批两条进化（M5.0 P0）
| 前置武器 | 进化名称 | 条件（全部满足） | 真正改变的战斗行为 |
|---|---|---|---|
| 电磁步枪 | **轨道歼灭炮** | 步枪 Lv.5 + 持有「穿甲弹」或「弱点扫描」 | 步枪弹丸额外穿透 2 个目标，伤害提高，发射时可见贯穿轨迹 |
| 散射炮 | **毁灭者霰弹炮** | 散射炮 Lv.5 + 持有「扩散核心」或「强化弹头」 | 追加多弹丸与较强近距离击退，形成可控的近距离清场能力 |

- 进化消耗一次局内升级选择，不消耗波后战术卡。
- 已进化武器不再出现重复进化选项。进化不会覆盖/移除已有卡牌。
- 如果玩家先选前置卡再升级到 Lv.5，或先 Lv.5 后获得卡牌，均能在下一次经验升级看到进化选项。
- 电弧/火焰的进化留到 M5.1；本次只具备五级的成长，不应提前展示不可选的进化承诺。
- 进化后的卡牌/结算和武器标记清楚展示名称；核心效果可在纯规则单测中验证，而不仅是图片变化。

## 6. 局内升级的通用选项（弱于波后卡）
| 选项 | 即时效果 | 限制 |
|---|---|---|
| 战斗校准 | 全武器基础伤害 +8% | 可以重复 |
| 快速供能 | 全武器攻击频率 +8% | 可以重复 |
| 机动推力 | 移动速度 +7% | 可以重复 |
| 应急维修 | 当前生命 +1，不超过最大值 | 满血不提供，或从候选池移除 |

升级增益与波后卡乘法叠加。所有效果作用于当前 run-level 属性，不污染全局静态定义。

## 7. 波末三选一定位
- 原有的 22 张波末卡牌全部保留作为 **高价值战术模块**，不额外叠加新的付费/货币流程。
- 新武器卡、穿甲弹、暴击、范围等仍在波末出现；新武器模块安装后自动校准到 Lv.2，使其在中后期也有足够战斗力。
- 通用波末卡原有 +25% 伤害/射速等保持现有数值，比局内单次 +8% 更强。
- 前四次波后仍保证至少一个可装备的新武器选项（若已四把则用普通合法卡补足）。
- 将两个弹窗明确区分：「战斗升级（高频轻量）」和「波后战术模块（低频强力）」。

## 8. HUD、交互与结算
- 顶部额外显示 Lv、当前XP/下一等级XP、细进度条；不得遮挡装甲、波次、时间、首领血条。
- 选卡弹窗短屏可滚动，所有选项文字和触控目标清晰，点击后无双重选择。
- 显示当前四把武器的「等级 / 进化」文字概况（尽量复用战斗底部状态文本，不持续堆叠 HUD）。
- 等级升级必须有短暂提示，选完才能继续移动/攻击；无额外手动技能按钮。
- 结算至少有「本局等级」「已进化武器数」，可继续查看所持武器信息。
- 选卡与浏览器隐藏/失焦暂停配合，不产生游戏逻辑追帧。

## 9. 数值与性能约束
- 最多 4 把武器、单武器最高 5 级；最多两种已实现进化。
- 枪械附加穿透次数和散射弹数有明确硬上限；既要实际改变攻击机制，也不能无限爆炸或无限复制弹丸。
- 自动攻击/碰撞的性能预算优先；多段连锁、弹丸数量、临时特效都应受现有手机性能预算约束。
- 经验来源只有同步击杀事件。不要额外增加大量地面经验球、磁吸模拟与每帧扫描。
- 升级时 world time 停止，恢复不补偿期间经过的真实时间。
- 战斗开始/重新开始必须重置等级、XP、武器等级、进化、升级队列和弹窗。

## 10. 技术拆分
1. 纯领域层 `src/game/arsenal.ts`：XP、等级阈值、武器等级、进化规则、合法升级池、升级数值和选择结果。
2. `GameScene`：击杀 XP 同步发放；升级队列/暂停状态；接入四武器攻击公式；HUD 与波后奖励的状态衔接。
3. `src/main.ts`：监听 `swarm:levelup`，显示三选一 DOM 选项；点击提交后显式恢复战斗。
4. `src/styles.css` / `index.html`：局内升级面板与窄屏适配。
5. `tests/arsenal.test.ts`：独立规则测试；已有战斗、卡牌、部署测试回归。
6. `README.md` 和本 PRD 同步更新。
7. CI 通过后 fast-forward main，自动发布，核对公开 URL 对应提交 SHA。

## 11. 可执行验收用例（P0）
- AC01：开局 Lv.1 0XP，只有步枪 Lv.1；重开之后完全归零。
- AC02：普通虫 +1XP，精英额外 +4，自爆自毁 0；Boss/连锁击杀不重复发 XP。
- AC03：连续获得大量 XP 可跨级，升级机会不遗漏；经验条上下限正确。
- AC04：升级界面三选一、不能选择不在 offer 中的项，选择期间不推进敌人和伤害。
- AC05：已装备武器可从 Lv.1 升至 Lv.5；Lv.5 不再出现升级到 Lv.6 的选择。
- AC06：未装备武器不能在局内升级；波后新装备直接 Lv.2。
- AC07：步枪 Lv.5 + 穿甲弹/弱点扫描后进化有效；未满足条件时不能进化。
- AC08：散射炮 Lv.5 + 扩散核心/强化弹头后进化有效；未满足条件时不能进化。
- AC09：轨道歼灭炮有实际额外穿透；毁灭者霰弹炮有实际更多弹丸与击退。
- AC10：波末卡选择和局内升级不会同时显示，选卡后续关卡正常。
- AC11：所有武器等级/伤害/攻击间隔/弹数/连锁数量的纯规则边界单测通过。
- AC12：前后切后台、死亡/胜利、重复开始均无卡死和旧 modal 遗留。
- AC13：中端机长时间密集虫潮仍可操作，没有经验球造成的新对象洪峰；实际真机待验证。
- AC14：CI 测试、TypeScript、生产打包通过，生产部署的完整 SHA 验证通过后才宣布上线。

| 版本 | 范围 | 是否本次实现 |
|---|---|---|
| M5.0 | XP、三选一等级升级、四武器 1–5 级、两种进化、波间强力卡、UI/HUD/结算/测试 | **是** |

## 13. 风险与取舍
- **过多升级打断战斗**：阈值随等级递增，升级后暂停，允许将来按真机节奏增大 XP 门槛。
- **进化不容易触发**：进化合法时强制进入候选，前四波仍有拿武器/前置卡机会；用真实开局模拟检验可达性。
- **数值失控**：固定等级上限、武器等级上限、弹数/跳链/穿透预算；分解升级公式便于平衡。
- **UI 互相覆盖**：同一个时间点只展示一个成长弹窗，组件由战斗阶段状态驱动，切前后台不追帧。
- **测试误报“效果生效”**：单测覆盖实际调用的伤害、间隔、弹丸/跳链/击退参数，而不只测试卡牌状态对象。
- **发版安全**：不直接在未验证代码上更新 main；仅 fast-forward 已通过的验证分支，部署后比对 exact SHA。

## 14. 完成定义（Definition of Done）
所有 P0/AC01–AC12 自动或流程验证通过，文档与 README 对齐，GitHub Actions CI 全绿，部署工作流显示成功且公网资源版本 SHA 匹配。真实手机体验指标 AC13 是发布后的人工验收项，不把 CI 通过冒充已完成真机验证。
