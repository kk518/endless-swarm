# 《无尽虫潮》后续路线图 v2.1：从 M5.3 原型到三幕 Roguelite

> 2026-11-11 · **后续内容属于产品规划** · 当前代码基线 M5.2 + M5.3（XP 无打断与虫潮可见性已实现）  
> 总纲：[PRD v2.4](PRD_V2.md) · 玩法详细设计：[三大支柱 / 三幕长局](PRD_ROGUELITE_CORE_LOOP.md)

## 0. 明确产品方向

新版本设计以用户确认的四条规则决策为准：

1. **每局都新鲜**：同一战区具有路线、事件、敌群、奖励和联动 Build 的可见变化。
2. **失败也爽**：资源战后结算，失败仍推进装备/科技/底盘解锁。
3. **Build 上头**：四武器进化只是底座；要有跨武器融合和主动幕间选择。
4. **不中断连续战斗**：每次 XP 升级不弹窗；战斗局允许延长到 **15–20 分钟目标**，但不能靠反复复制波次。

不要把“优先不上新代码”解释成永久不实现这些功能。此时先规划分包，逐个交付完整可验证的玩法闭环。

## 1. 新的系统依赖图

```text
M5.2 连续成长（已实现）+ M5.3 可见虫潮（已实现）
    ↓
M5.3 手机战斗可见性（宽视野 + 可见索敌 + 虫潮入场）
    ↓
M6.0 三幕长局 + 安全快照 + 基础战备结算/首级可购装备强化 + 阶段重大选择
    ↓
M6.1 两个资源战区 + 持久化资源结算 + 初级装备工坊
    ↓
M6.2 首批跨武器联动 + 各战区事件、精英和 Boss 变化
    ↓
M7.0 第三战区/晶体 + 深化装备 + 科技和机甲
    ↓
M7.1 横向挑战/更多联动/初始配置/成就
    ↓
M8 发行验证
```

所有版本都不以 FPS 数字作为产品阶段门槛，但**崩溃、触控失效、丢档、发奖重复**仍是必须修复的 P0。

### 2.1 M5.2 已完成的基础（历史验收规格）

现状 M5.1 每次 XP 到达阈值便暂停并打开三选一；玩家明确反馈打断体验。这是**已确认问题**而不是需要等待十人调查才能决定的假设。

P0：
- 战斗中由 XP 触发的升级弹窗数量 **0**。
- 开局默认训练倾向，已装备武器优先升级；其它升级流向玩家预选的辅助倾向。
- 武器进化条件仍为 Lv.5 + 波末前置材料，但自动触发；不再消耗必须弹出升级面板的一次选择。
- 波末原战术卡仍三选一，可在同一页面修改下一段专精。
- 允许玩家仅点击“出击”直接使用默认配置。
- XP、武器上限、溢出与每局重置、Boss 战斗暂停/结算的规则测试。

**通过条件**：能够连续打完当前整波没有 XP 模态；武器成长和进化实际生效；重要卡牌仍由玩家亲自选。

### 2.1a M5.3 竖屏战斗可见性

**这是玩家已明确反馈的问题：手机上视野太窄，虫子没露面就被自动火力消灭。** 当前逻辑宽 450，基础射程 360 > 左右可见半屏 225，刷怪半径约 325–463；镜头+武器+刷怪没有统一的“可见作战区”。

- 手机 zoom 初始建议 0.72–0.78（参考 0.75），横向可见半径约 300；缩放后的机甲/危险预警保持可读。
- 基础自动武器仅主动锁定相机安全可见区域内目标，短时保留边缘锁定；狙击/英雄远距武器可以有限例外。
- 虫潮从画面边缘带短预警出现，让玩家**先看到虫群运动，再看到火力清场**；精英/Boss 入场有更强辨识。
- 镜头变化不能改变世界移动速度、真实射程、XP 与伤害；HUD 和手机摇杆保持同样触控空间。
- 分别验证纯 zoom 与「zoom + 可见索敌 + 入场预告」方案，不能仅缩小角色就算完成。

详细规则及验收见 [手机战斗视野 PRD](PRD_MOBILE_VISIBILITY.md)。

### 2.2 M6.0 三幕与长局恢复

初版先在**一张已具备可玩内容的战区**建立三幕架构，每幕含约 3 个遭遇段落。设计目标为 15–20 分钟战斗，而不是把 5 波倒计时乘三。

P0：
- 每一幕产生至少一个不同的战术变化（敌方组合、精英、可选目标或位置变化）。
- 约 6–10 次重要奖励/路线决策，安排在段落/幕间，不恢复每级弹窗。
- 第一幕让玩家找到第二武器或主模组，中幕形成配方和跨武器构筑，终幕验收 Build。
- **安全节点快照**：暂停/退出/重新进入可从最近完成节点恢复，保留随机种子、出装、已领取奖励和结算状态。
- 不允许重复抽取奖励、重打精英套取材料或利用刷新跳过死亡结算。
- **同版本最小永久成长闭环**：有效失败也获得少量通用战备数据，存入版本化存档，并能购买主武器框架第一级强化且下局生效。不能让失败的 20 分钟什么都不留下。

**通过条件**：长局不依赖同质波次填充，退出恢复没有双发奖/丢档；有效失败后看得见战备所得，并有明确可购买的永久强化目标。

### 2.3 M6.1 资源战区与工坊

**“资源产地”与“素材可消费装备”必须同版本实现**，不能只有几张战场卡和一串素材数字。

P0：
- 钢铁遗迹（军用合金）和感染巢穴（生体样本）可以出击；两图有真实的敌群/事件或环境战术差异。
- 在 M6.0 通用战备结算基础上，加入**合金和样本的原子结算**；失败有合理获得，秒退刷资源受限。
- 装备工坊开放主武器框架和装甲模块低阶升级，消耗对应资源；升级后下一局真实生效。
- 从工坊查看缺料后可直接去主产战区。
- 仅在本版本已经上线的战区中要求玩家收集材料；不能先要求雷暴晶体再解锁雷暴地图。
- 独立战区选择与后续不同资源不会篡改 XP/波末卡/武器进化规则。

**通过条件**：玩家能完成“目标装备 → 切战区 → 失败或胜利获取材料 → 买强化 → 再出击”一次闭环。

### 2.4 M6.2 英雄身份与战斗协同机制

M6.2 首批必须交付真实的英雄体验闭环：**可选凯恩/灰烬/伊芙，三人都有独特被动及独立专属自动武器**。详细的第一批英雄/六武器/两融合、D1–D8 奖励和技能触发合同见 [垂直切片 PRD](PRD_HERO_BUILD_VERTICAL_SLICE.md)。选择英雄不锁死普通武器；机甲底盘独立于英雄。先让普通武器池从现有四种扩至约六种、验证组合强度，再决定是否开放后续六种。

具体名单、被动、英雄武器规则、配方与奖池见 [英雄武器系统 PRD](PRD_HERO_WEAPON_SYSTEM.md)。



当前四条武器**单独进化**保留。M6.2 的新核心不是第五把武器，而是给两武器、状态、模组之间做机制联动：

- 第一组推荐：**雷霜封锁**（连锁电弧传播减速/电荷）。
- 第二组推荐：**炼狱引爆**（霰弹命中灼烧目标引爆局部火伤）。
- 协同必须改变伤害/控制/传播逻辑，不能仅有 +X% 伤害说明。
- 抽卡池采用协同候选 + 转型候选 + 通用兜底；允许做出 Build，不保底每局全拿最强套。
- 允许普通“单武器深化构筑”仍有通关路径，不强制每局双武器融合。
- 随机事件首先服务于构筑验证，不为了图多乱塞五种事件。

**通过条件**：真实战斗机制能用纯规则和整局测试验证；不同流派强项、弱项可以用玩家可理解的语言描述。

### 2.5 M7.0 机库、三战区经济与更多英雄

规划追加**零/幽灵游侠**和**堡垒/铁血守卫**，将英雄的机动型/部署型玩法与通用机甲底盘独立组合；不把后解锁英雄做成初始英雄的纯数值上位替代。



- 雷暴前哨产反应晶体；第三战区不是前两张地图换色，有周期性能源危险与不同敌方生态。
- 完成四个工坊槽位（框架、装甲、推进器、能源）。
- 开放有限的全局研究和三种机甲底盘；研发与工坊增益**有统一总预算**，不能重复无限放大火力。
- 长局快照与永久结算、购买扣费各自幂等，存档版本迁移不会丢旧余额。
- 机库选择影响战斗风格和风险承担，不允许购买优势后默认变成无脑站桩必赢。

### 2.6 M7.1 终局目标

规划加入**薇拉/虫巢猎手**，六位英雄各自拥有专属武器与被动；武器池长期目标十二把普通武器，但仅在测试确实提高随机新鲜感后逐步扩池，避免卡牌稀释导致关键 Build 不可达。



- 剩余两个跨武器流派原型：磁轨风暴、壁垒熔炉（如前两个真实获得认可）。
- 起始武器/底盘组合，挑战契约与成就，随机种子挑战。
- 不将“每天登录”当成长期留存；用户应因想尝试新的强力组合和战场路线而回来。

## 3. 战斗中随机性的产品约束

四层随机：**空间/路线、敌方生态、局内事件、构筑奖励**。

- 同战区的三局不应完全相同，但必须避免随机出生点挡住玩家或突然必死。
- 奖励三选一中优先至少一个可与现有构筑衔接的合法候选、一个新方向、一个通用兜底。
- 可复现 seed **分离战斗随机和奖励随机**，不让某一次子弹碰撞改变所有后续构筑抽卡。
- 一次只触发有限数量的重要事件，重要奖励应与风险有关，玩家可选择更难的路线。
- 不把战场随机性实现为“把五波怪数量随机改高低”这么单薄。

## 4. 局外经济和长局结算原则

- 三种地区素材：合金、样本、晶体。对应装备属性与战区用途，各图不会因后期解锁新图而失去素材价值。
- 通用战备数据：基础科研、机甲授权与工坊的通用成本。
- **结算公式需要按“长局多遭遇节点”改写**。旧 M7 的“每完成一波 +6”模型仅适用于旧五波原型，不能在三幕九段结构中照搬。
- 失败根据**已完成节点、击杀、风险目标**得到资源，通关再额外加成；无胜利即全清的惩罚。
- 完成结算一次性保存所有奖励，快照恢复不能重复领取。
- 装备费用应结合“首次升级大概 1–2 次有效出击”进行实测校准，防止刷三十分钟才得到小幅提升。

## 5. 主要项目风险与应对

| 风险 | 应对 |
|---|---|
| 一局长到 20 分钟却只是重复刷怪 | 三幕各有明确节奏、风险路线、Build 阶段与可选择的目标 |
| 自动 XP 把 Build 决策全删了 | **只自动小升级**，保留约 6–10 次幕间有分量的奖励/分支选择 |
| 过度定向掉卡导致每局都凑同样流派 | 协同+转型+通用奖励结构；开放流派切换和随机事件 |
| 过度随机导致进化全靠运气 | 明示配方，建立合法候选和相应方向的出现机会 |
| 失败局十多分钟一无所得 | 有效进度阶段结算，提前让玩家看到资源与下一升级目标 |
| 永久属性使所有战区变成扫荡 | 工坊/研究预算，底盘有代价，更大收益以玩法机制解锁 |
| 浏览器关闭损失 20 分钟 | 幕间安全节点快照、恢复与幂等结算必须先做好 |
| 三张战区/所有装备同时开工 | M6.1 先两图两素材两装备；M7.0 再第三图和完整装备 |
| 性能优化占据设计优先级 | 按用户要求不把 FPS 当本轮门槛；仍守住不崩溃、不断触控和不丢数据 |

## 6. 版本验收与下一步产品决策

- **M5.2**：打完一段战斗 0 次经验升级弹窗，波末能表达自己的构筑方向。
- **M5.3**：基础自动武器不再持续击杀从未进入过手机画面内的虫子；侧向虫潮能够可见入场并被轰碎，机甲与预警仍清晰。
- **M6.0**：一局可体验三幕和有意义的多次决策；中断可恢复，重要战利品不会被刷新重复领。
- **M6.1**：玩家能选两图、刷地区素材、升级两件装备并重新出击；失败仍有合理合法收益。
- **M6.2**：至少两种联动流派有实际机制质变且不是唯一可胜玩法。
- **M7.0**：完整地区素材—装备—科技/机甲链条，资源不会因为缺产地卡死。
- **M7.1**：玩家愿意为了尝试不同挑战/构筑继续重开，而不是被每日任务强制绑定。

**待真实数据确认**：最佳局长区间、重大选择次数、获取第一项永久装备升级的局数、同图复玩的变化感、融合流派完成率。没有实测不能宣称这些目标已达成。

---

**产品原则：做一款好玩的 15–20 分钟机甲肉鸽，不是把 4 分钟原型拖成长时间刷钱游戏。**
