## 1. 产品概述

### 1.1 一句话定位
《无尽虫潮》是一款**单指移动、自动瞄准射击**的俯视角科幻虫潮生存 Roguelite：玩家操控一名原创动力装甲战士，在密集异星虫潮中走位求生；**移动时持续开火，停下后进入高火力展开状态**；每波结束三选一抽卡，组合武器和强化，最终击败虫族首领。

### 1.2 灵感来源与差异化
- 借鉴《僵尸危机3》的密集敌潮、武器反馈与极限生存节奏。
- 借鉴《土豆兄弟》的自动战斗、多武器组合、短波次和局内构筑。
- **原创差异化**：无攻击键、只用一根手指完成操作；机动/站桩双姿态；科幻动力装甲与原创虫族世界观。
- 不复用其他作品的角色、名称、地图、美术、音效或具体设定。

### 1.3 目标玩家与场景
- 喜欢快节奏割草、幸存者类游戏、武器成长和 Roguelite 构筑的手机玩家。
- 主要场景：碎片时间、竖屏、单手操作、3～6 分钟一局。
- **玩家承诺**：5 秒内进入战斗；无需学习射击操作；每波成长都能被明显感知。

## 2. 产品目标与验证指标

### 2.1 V0.1 的唯一核心问题
不依赖剧情、签到、排行榜或复杂养成，仅凭**走位、自动射击、站桩爆发、波后抽卡**，能否让玩家主动再来一局？

### 2.2 试玩验证标准（小样本方向性指标，非商业 KPI）
| 指标 | V0.1 目标 | 获取方式 |
| --- | --- | --- |
| 上手速度 | ≥80% 初次试玩者在 15 秒内理解如何移动和攻击 | 观察 5～10 位未看说明的试玩者 |
| 核心爽感 | ≥70% 认为射击/清怪过程“有趣”或“很有趣” | 试玩后 5 分制问卷 |
| 主动重开 | ≥60% 完成或失败后主动开启第二局 | 试玩行为记录 |
| 姿态博弈 | 玩家能说出“何时站住、何时移动”的具体决策理由 | 访谈/回放 |
| 基础运行 | 主流中端手机基本保持 ≥30 FPS，目标 60 FPS | 真机压力测试 |

> 达不到“爽感”和“主动重开”门槛，优先重做战斗手感，不扩大内容规模。以上数字为开发阶段的暂定判断阈值。

## 3. 核心游戏循环

1. 玩家点击“开始”，战士出现在异星竞技场，武器立即自动寻找敌人。
2. **战斗阶段**：单指走位；武器持续自动瞄准、射击；可短暂停下获得站桩火力加成。
3. **波次结束**：敌人退场，战斗暂停，出现 3 张随机强化卡。
4. 玩家只选 1 张，强化立即生效，进入下一波。
5. 第 5 波迎战虫族首领；死亡或通关进入结算，可一键重开。

**V0.1 不引入经验拾取、货币商店、局外属性升级**，避免出现两套竞争的成长流程。

## 4. 核心操作与战斗规则

### 4.1 单指移动
- 采用**浮动虚拟摇杆**：手指按住屏幕下半区域时以触点为摇杆中心，向任意方向滑动即可 360° 移动。
- 适配左/右手拇指，摇杆不遮挡角色；可在设置中切换固定/浮动摇杆（固定模式属于后续可选优化）。
- 松开手指即停止移动；无主动攻击、瞄准、换弹按钮。
- 抽卡阶段只需单指点选卡牌；HUD 与安全区域需适配刘海屏。
- 新手引导不超过一屏：**“滑动移动；松手强化火力；武器自动攻击。”**

### 4.2 自动索敌与开火
- 装备的所有武器**独立自动索敌、独立冷却、独立开火**；最多 4 个武器槽。
- 基础目标策略：优先选择射程内最近的可攻击敌人，已锁定目标未死亡或离开射程时保持锁定，避免频繁转向抖动。
- 不存在瞄准按钮；移动时攻击不中断。各武器使用相应子弹、锥形范围、连锁或持续伤害效果。
- V0.1 不做手动换弹；武器通过射击间隔、射程、弹道和伤害表现区别。
- 击中必须提供清晰反馈：受击闪烁/击退（按敌种）、命中音、伤害/死亡特效；反馈不应遮挡敌人的攻击预警。

### 4.3 双姿态：机动模式 / 火力展开模式
| 状态 | 触发 | 规则 |
| --- | --- | --- |
| 机动模式 | 玩家正在移动 | 以基础伤害与基础射速持续自动攻击 |
| 展开蓄力 | 完全停止移动 | 连续静止累计 0.8 秒；仍按基础属性开火 |
| 火力展开 | 静止累计 ≥0.8 秒 | 造成伤害 ×1.35，攻击频率 ×1.25，展示装甲稳定器和地面光圈 |
| 退出展开 | 再次发生有效移动输入 | **立即**恢复机动模式，无僵直、无射击中断 |

**平衡原则**：站桩必须是“承担包围/远程攻击风险以换取输出”，不能成为无脑最优解。数值均为待测试初值，后续允许通过配置调整。敌人攻击前摇必须清晰，避免玩家刚进入展开就遭受不可预知的伤害。

### 4.4 生命、伤害与死亡
- 玩家具有生命值；接触敌人或被投射物命中会损失生命，短暂受击无敌帧（初始建议 0.5 秒）防止瞬间连扣。
- 生命归零即本局失败，展示最高波次、消灭虫数、主要强化卡，并提供“一键再来”。
- 本局之外不保留永久战力；可以保留本地最佳记录（localStorage）。

## 5. MVP 内容设计

### 5.1 角色与场景
- **1 名原创动力装甲战士**，正面/背面/侧面简洁可辨识，移动与展开两种状态明显不同。
- **1 张异星竞技场**：优先开放式地形，少量不会卡住玩家的障碍物；角色保持在镜头中心附近。
- 原创虫族设计采用清晰轮廓、颜色/动作区分敌种；不使用战锤等现有 IP 的标志性名称与造型。

### 5.2 武器（4 种）
| 武器 | 战斗功能 | 构筑方向 |
| --- | --- | --- |
| 电磁步枪（初始武器） | 中远程单体连续射击，命中稳定 | 射速/穿透 |
| 散射炮 | 近距离扇形多弹丸，高爆发 | 站桩爆发 |
| 电弧线圈 | 对附近敌人造成连锁电击 | 群体清场 |
| 火焰喷射器 | 中近程锥形持续伤害 | 范围/持续伤害 |

- 开局拥有电磁步枪；其余武器可由波后卡牌获得。
- 任何时候最多 4 个武器槽；满槽时不再生成“获得新武器”的无效选项。
- 升级可影响弹数、穿透、连锁、范围等实际表现，不只是数值叠加。

### 5.3 敌人（4 种普通虫 + 1 首领）
| 敌人 | 行为 | 对玩家造成的压力 |
| --- | --- | --- |
| 工虫 | 缓慢追踪、数量多、血量低 | 制造虫海 |
| 跃袭虫 | 快速突进，突进前有动作提示 | 迫使玩家走位 |
| 甲壳虫 | 移动缓慢、高生命/护甲 | 阻挡通道，考验持续输出 |
| 喷酸虫 | 与玩家保持距离，发射有预警的酸液 | 克制长期站桩 |
| 虫巢巨兽（Boss） | 交替冲锋、范围预警、召唤工虫 | 综合检验移动与火力展开 |

- 关键信息优先通过体型、颜色、动画和地面预警表达；低龄/休闲用户无需读文字即可反应。
- 敌人生成不得直接贴脸；初期从屏幕可见边缘附近逐步涌入。

## 6. 波次节奏

| 波次 | 目标时长（测试初值） | 敌人/事件 | 结束奖励 |
| --- | --- | --- | --- |
| 1 | 35 秒 | 少量工虫，帮助理解移动和自动射击 | 三选一 |
| 2 | 40 秒 | 更多工虫 + 跃袭虫 | 三选一 |
| 3 | 45 秒 | 引入甲壳虫，形成局部拥堵 | 三选一 |
| 4 | 50 秒 | 引入喷酸虫，逼迫玩家离开站位 | 三选一 |
| 5 | 60～90 秒 | 虫巢巨兽 + 少量增援 | 通关结算 |

- 波次 1～4 使用计时制；到时剩余小怪以明确退场特效消失，随后暂停进入抽卡，不让清场等待破坏节奏。
- 第 5 波以击败 Boss 为主要通关条件，必要时设置超时/失败兜底，避免极端拖局。
- 单局目标 **4～6 分钟（包括选卡）**；新手第一局可以失败，但失败应可归因、愿意再试。

## 7. 波后抽卡与构筑系统

### 7.1 抽卡规则
- 每通过第 1～4 波，**免费随机展示 3 张卡，玩家选择且仅选择 1 张**。
- 选卡时游戏世界完全暂停；无抽卡货币、无广告、无付费重抽。
- 可选池依据武器槽、已获得的强化和互斥规则筛选，避免无效卡和重复无意义选项。
- 前两次抽卡至少有一次可获得新武器，保证早期能体会多武器组合。
- 选卡后展示一句简短反馈，并立即进入下一波。

### 7.2 第一批卡牌池（建议 16 张）
| 类别 | 卡名 | 效果方向 |
| --- | --- | --- |
| 新武器 | 散射炮组件 | 获得散射炮 |
| 新武器 | 电弧线圈组件 | 获得电弧线圈 |
| 新武器 | 喷火模块 | 获得火焰喷射器 |
| 通用火力 | 高速供弹 | 所有武器射速提高 |
| 通用火力 | 强化弹头 | 所有武器伤害提高 |
| 通用火力 | 穿甲弹 | 弹道穿透敌人数 +1（仅适用弹道武器） |
| 通用火力 | 连环爆裂 | 击杀时概率触发小范围爆炸 |
| 通用火力 | 扩散核心 | 散射/范围类效果覆盖更广 |
| 机动流 | 磁悬浮推进 | 移动速度提高 |
| 机动流 | 冰霜弹头 | 命中短暂减速（带内置触发限制） |
| 机动流 | 战术余热 | 刚开始移动后短暂保留部分展开增益 |
| 站桩流 | 快速支架 | 缩短火力展开蓄力时间 |
| 站桩流 | 超载反应堆 | 展开模式额外提高射速，但伴随过热限制 |
| 站桩流 | 钢铁壁垒 | 展开时获得有限减伤 |
| 生存类 | 应急修复 | 回复一定生命值，不超过最大值 |
| 生存类 | 装甲加固 | 提高最大生命值并获得少量当前生命 |

**卡牌设计约束**：效果必须可实现、可见、可解释；强度可后续调整。特殊触发卡需要冷却与性能限制，避免爆炸连锁导致设备卡顿。

### 7.3 目标构筑体验
- **站桩炮台**：散射炮 + 快速支架 + 钢铁壁垒。
- **游击风筝**：电磁步枪 + 冰霜弹头 + 磁悬浮推进。
- **清屏电网**：电弧线圈 + 扩散核心 + 连环爆裂。

V0.1 只需证明至少 2 种流派在操作感和击杀方式上有明显差异，不追求完整装备图鉴。

## 8. 界面、视听与易用性

### 8.1 竖屏页面
- 战斗 HUD：顶部显示血量、当前波次、倒计时；不遮挡主要可视区域。
- 底部保留单指操作区，浮动摇杆仅触控时显示；开局有极简操作指引。
- 展开模式有明显的装甲动画、角色轮廓变化或地面光圈；蓄力阶段有小型进度提示。
- 抽卡界面：**3 张卡并列或适配窄屏的纵向排列**，卡面显示名称、图标、核心效果、适用武器。
- 结算界面：存活波次、击杀数、使用武器、所选卡牌与一键重开。

### 8.2 战斗反馈与无障碍
- 优先实现射击声音、命中特效、受击闪白、击杀粒子和适度屏幕震动。
- 敌人远程攻击和突进需要显著预警；重要信息不能只依赖颜色。
- 性能下降时优先减少粒子和伤害数字，保留敌人位置、弹道和预警。
- 音频遵循手机浏览器用户交互后才能播放的限制；默认允许静音切换。

## 9. 技术与非功能需求

- 引擎：Phaser 3；TypeScript；Vite；独立静态站点，不依赖后端即可试玩。
- 目标浏览器：iOS Safari、Android Chrome 的近期主流版本；同时支持桌面键盘/鼠标作为开发调试输入。
- 自适应：9:16 到常见全面屏比例，考虑横纵安全区域；游戏逻辑不依赖固定像素坐标。
- 性能：目标 60 FPS，中端真机高压场景底线 30 FPS；优先使用对象池、空间查询与受控生成数量。
- 首版压测场景：约 100～150 只活跃虫族（作为工程测试目标，实际数量由真机数据决定）。
- 数据：本地保存设置和最佳成绩；不收集个人信息，不需要账号。
- 可维护性：武器、敌人、波次、卡牌参数数据驱动；战斗逻辑与表现分层；核心规则可单元测试。
- 开发流程：以 GitHub Issues/PR 管理，每次发布都可以通过手机 URL 实际试玩。

## 11. 迭代顺序与验收

### M0：可移动、能开火（首个可玩切片）
- 1 名角色 + 1 种虫 + 初始步枪 + 单指摇杆 + 自动射击 + 站桩增强。
- **验收**：在手机上，不打开说明也能移动、停下展开、持续清怪；视觉反馈清晰。

### M1：完整 5 波闭环
- 加入波次、4 武器、敌种、Boss、三选一卡牌和结算。
- **验收**：至少能连续完成一局；卡牌选择会改变下一波实际战斗；无阻断性 Bug。

### M2：手感与性能验证
- 调整移动惯性、开火节奏、命中/死亡反馈、生成密度与展开倍率。
- 组织 5～10 人盲测，记录主动重开、掉帧、死亡原因、构筑偏好。
- **验收**：完成第 2 节试玩指标评估；若结果不达标，以修改核心玩法为优先，而非增加功能。

## 12. 主要风险与应对

| 风险 | 应对 |
| --- | --- |
| 自动射击缺乏参与感 | 用敌人包围、突进和酸液预警，使走位始终重要 |
| 站桩模式无脑最强/过弱 | 通过展开延迟、倍率、远程敌人与地形反复测试 |
| 抽卡效果不明显 | 先做有可见差异的多弹、连锁、爆炸，而非只有小百分比 |
| 虫群造成手机卡顿 | 对象池、生成预算、粒子降级、真实设备持续测试 |
| 首版开发范围膨胀 | 以五波可玩闭环为唯一交付目标，其他均推迟 |
| 题材与现有 IP 相似 | 原创虫族、动力装甲、名称、符号和美术；上线前开展商标核查 |

## 13. 待通过试玩决定的问题

1. 展开蓄力 0.8 秒是否足够自然？伤害 ×1.35、射速 ×1.25 是否有吸引力？
2. 4 武器槽在 4 次抽卡机会下是否足够形成差异？是否应调整初始武器数或奖励次数？
3. 浮动摇杆是否真正适合左右手单指操作？需要多大死区与灵敏度？
4. 虫群规模和敌种组合能否在中端手机上同时保持压力与可读性？
5. 画面风格更适合清晰卡通、轻像素还是低多边形？以原型可读性优先。
6. 核心玩法通过验证后，再研究 App 封装、商业化和长期留存，不提前植入付费限制。

---

**本版结论**：先做一个“打起来就很爽”的五波手机原型。决定继续投入的证据应来自真实试玩，而不是功能数量。
