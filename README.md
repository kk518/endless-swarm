# 无尽虫潮 · Endless Swarm

> 一人，一甲，万千虫潮。

一个为手机竖屏和单指操作设计的原创科幻生存射击 Roguelite。参考《僵尸危机3》的虫潮压迫感与《土豆兄弟》的自动射击 / 构筑节奏，但采用独立的原创科幻角色、美术与世界观。

## 当前进度：M0 战斗原型

目前可游玩：
- 手机滑动浮动摇杆移动（支持左右手）；电脑用 WASD / 方向键。
- 武器自动寻找附近虫族，边移动边持续开火，无射击按钮。
- 停止移动 0.8 秒进入**火力展开**：伤害 ×1.35、射速 ×1.25；移动立刻取消，无僵直。
- 虫族持续从四周靠近、不断增加的生成压力、命中/击杀粒子反馈、受伤无敌帧。
- 使用 60Hz 固定逻辑步；切后台/失焦时暂停战斗并释放摇杆，返回后不会瞬间追帧。
- 触控操作区域限制在屏幕下方，避免操作遮挡上方战斗画面；旋转和视口变化时适配布局。
- 装甲血量、击杀数、生存时间、最佳击杀记录和一键重开。
- 无外部素材依赖：角色、虫子、枪械与地表都由矢量图形程序生成；简单 Web Audio 音效。

**尚未实现：** 五波关卡、波后抽卡、四把武器、精英虫/Boss。这些属于 M1，见 [完整 PRD](docs/PRD.md)。不要将当前原型称为完整游戏。

## 本地启动

需要 Node.js 22+：

```bash
npm install
npm run dev
```

打开 Vite 输出的本地网址。要在手机真机试玩，确保手机和电脑处于同一局域网，打开电脑的局域网 IP + Vite 端口（默认 5173）；或将构建目录部署为静态站点。

## 验证与构建

```bash
npm test          # Node 22 内置测试：索敌、展开、移动、刷怪节奏
npm run typecheck # TypeScript
npm run build     # 生成 dist/ 静态站点
npm run preview
```

GitHub Actions 对 push/PR 自动运行测试与构建；构建产物以 Artifact 形式保留（不自动公开部署）。

## 主要文件

- `src/game/GameScene.ts`：游戏循环、输入、自动射击、敌人、碰撞、视觉反馈
- `src/game/combat.ts`：纯逻辑与平衡参数（可单元测试）
- `src/game/Art.ts`：程序生成原创图形素材
- `src/game/Sound.ts`：合成音效
- `src/main.ts`：游戏初始化、开始/结算/重玩 UI
- `docs/PRD.md`：整体设计与后续里程碑

## 设计底线

优先验证用户是否会主动重开一局，而非功能数量。每完成一个里程碑，都应在手机上实际试玩并调整射击反馈和展开/走位的平衡。项目素材与设定保持原创。
