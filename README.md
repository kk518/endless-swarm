# 无尽虫潮 · Endless Swarm

> 一人，一甲，万千虫潮。

手机竖屏、单指操作的原创科幻虫潮生存 Roguelite。灵感来自经典俯视角虫潮/幸存者游戏，角色、敌人与视觉素材均为原创。

## 当前进度：M5 · 战地进化（局内升级与武器进化）

- 单指浮动摇杆 360° 移动（桌面支持 WASD / 方向键），自动锁敌、自动开火。
- 停止移动 0.8 秒进入动力装甲火力展开：伤害 ×1.35、射速 ×1.25；移动立即取消。
- **五波完整战斗**：前四波按计时推进，第五波击败虫巢巨兽通关。
- **每波结束免费三选一**：22 张技能卡，武器、火力、站桩、机动与生存流派。
- **四武器可视挂载**：手持电磁步枪、左肩散射炮、右肩电弧线圈、背部喷焰器；选取对应卡后机体立即安装新模块，最多四把武器独立瞄准和攻击。前四次波后奖励都会优先展示尚未获得的新武器。
- 工虫、跃袭虫、装甲虫、喷酸虫、**自爆虫**（第三波起加入，预警 0.85 秒后爆炸）、虫巢巨兽（第五波首领）。
- **连杀增伤**：4.5 秒内持续击杀累计连杀，5 / 10 / 20 连杀触发 +10% / +20% / +30% 伤害；受到攻击会中断连杀。
- **M2 三张卡**：战斗狂热、战地回收、弱点扫描（最高 42% 双倍暴击）。
- **M3 精英虫**：第二波起概率生成金色精英虫，生命和冲击力更高；场上最多 3 只，击杀后掉落补给。
- **战场补给箱**：每约 22 秒投放一次，移动接近拾取；掉落装甲修复、8.5 秒 +45% 射速超频或范围 EMP（伤害敌人并使其短暂减速）。补给 22 秒后消失，最多同时存在 7 个。
- **M3 三张新卡**：磁力回收臂（拾取范围 ×1.8）、聚变蓄能器（超频延长至 13 秒）、脉冲阵列（EMP 伤害和半径增加）。
- 命中特效、虫族预警、装甲血量、首领血条、击杀计数、结算与一键重开。
- Phaser 3 + TypeScript + Vite，纯前端静态站点，无账号和后端依赖。

### M3.1 玩法与可见反馈修复

- **强化卡即时确认**：选择卡后显示卡牌名称及生效提示，战斗 HUD 持续显示来自实际 `RunBuild` 的火力、射速、移速与暴击属性；新波次保留所选构筑。
- **强化卡战力提升**：高速供弹与强化弹头各 +25%，推进器移速 +22%，扩散核心覆盖 +25%；原先完全依赖随机补给触发的磁力回收臂 / 聚变蓄能器 / 脉冲阵列增加常驻移速 / 射速 / 伤害收益。
- **散射炮修复**：范围提升不再额外扩大散弹锥角，避免强化后反而更难命中。
- **全套卡牌回归测试**：22 张卡均需真正改变战斗属性或解锁可用能力；伤害、攻速、姿态与关键条件效果使用战斗实际调用的纯函数验证。
- **虫潮压迫感**：每波不同的刷新节奏与组群规模，随着波次和剩余时间升级；虫族接近速度提高，从行进方向和两侧夹击，每约 14.5 秒触发一次提前预警的集中虫潮。
- **移动端性能约束**：保留每波活动虫族数量上限、精英最大三只以及原有粒子上限。实机需要继续验证帧率、难度与伤害体验。

### M4 · 军武硬科幻 × 暗黑生物科幻

- **战士**：重新设计工业动力装甲的分层轮廓，肩部装甲、光学面罩、警示橙细节和胸核；站桩展开出现可辨认的四组装甲支架。
- **虫族**：工虫、跃袭虫、装甲虫、喷酸虫、自爆虫和虫巢首领分别采用原创手工设计的专属纹理、头骨/肢体比例与甲壳结构。精英有独立轮廓框而非仅换色。
- **战场**：重绘旧军事设施、破损安全条、板块缝隙和菌毯侵蚀。独立脚下阴影、命中反馈和有限寿命的地面虫血痕迹营造俯视 2.5D 层次。
- **UI 与战术授权台**：新阵营徽章、克制的枪灰/骨白/琥珀色盘、工业直角面板、切角强化卡与模块编号。移动端保留可读性和操作空间。
- 所有纹理来自 Phaser Graphics（同步离线生成），无下载资产和大型后处理，确保手机端稳定性。

### M5 · 战地进化

- **击杀获得经验**：直接计入战术经验，无需停手捡经验球；每次升级会暂停虫潮弹出「战斗升级」三选一。
- **经验等级**：Lv.1–25，需求逐级递增，跨级经验保留；旧波次节奏和单指移动不变。
- **四把武器各自升级**：最高 Lv.5；实际改变伤害、攻速、散射弹丸、跳链次数及火焰射程。波后获得新武器时自动校准至 Lv.2。
- **两条首批进化**：步枪 Lv.5 + 穿甲/暴击前置 → 轨道歼灭炮（额外穿透、增伤）；散射 Lv.5 + 范围/强化弹头 → 毁灭者霰弹炮（更多弹丸、击退）。
- **成长双通道**：局内经验升级提供小幅频繁强化（伤害/射速各 +8% 等），波末 22 张战术卡保持高强度奖励和新武器解锁。
- **可视状态**：顶部经验等级与 XP 条，战斗中显示各武器等级及进化标记，结算显示本局等级与进化数量。
- **纯规则测试**：经验阈值、跨级、候选池合法性、等级上限、进化条件和实际武器数值。
- 完整需求与验收见 **[M5 详细 PRD](docs/PRD_M5.md)**。原 PRD 是历史 MVP 基线，曾明确排除经验升级，不能用来验收 M5。

### M4.1 · MECH OVERDRIVE 火力表现

- **机甲人形修正**：减少上半身块状装甲，明确头盔、修长双腿、关节、双臂及背部推进单元，保留军武硬科幻质感。
- **四个物理挂载点**：步枪之外的散射肩炮、电弧线圈、喷火器采用完全独立的纹理和旋转位置；未解锁不显示。
- **真正分流的武器 VFX**：步枪热芯曳光；散射炮五弹丸和冲击扇面；电弧枪多段折线连锁闪电；喷火器半透明扇形火幕和炽热粒子。
- **强化立即点亮**：每选择一张卡，武器和装甲能源核心逐级增加冷/暖色光晕、枪口焰、能量尾迹及喷射粒子，最多三档，火力展开和超频状态再增强亮度。
- **打击感**：枪械后坐、命中环与暴击火花、精英和首领击杀时的短暂停顿与镜头轻震；各武器配有不同的原创合成射击音效。
- **移动端预算**：临时特效统一使用单个 Graphics 绘制，有限数目且短生命周期；枪口贴图不超过 32 个，保留原有粒子预算与敌人上限。

完整的 M4 视觉规范见 [美术规范](docs/ART_DIRECTION.md)。

本轮主要提升观感，保持单指移动、自动射击、四种武器的攻击数值、五波关卡和原有抽卡系统。

本版本仍属于**可玩性原型**。线上发布以 `main` CI/CD 的真实完成和版本 SHA 验证为准；需在手机上实际验收剪影辨识度、帧率与界面可读性。

## 本地运行

需要 Node.js 22+：

```bash
npm install
npm run dev
```

用手机和电脑处于同一个局域网时，访问开发机的 IP 与 Vite 输出端口；建议手机使用竖屏。

```bash
npm test           # Node 内置测试运行器（M0–M5 规则/成长/武器/美术/多挂载测试）
npm run typecheck  # TypeScript 严格模式检查
npm run build      # 静态构建输出 dist/
npm run preview    # 预览构建结果
```

CI 在 PR / feature 分支和 main 上运行测试、类型检查与构建，成功后上传静态产物。

## 游戏流程

1. 点「进入战场」，拖动下半屏摇杆移动，武器持续自动攻击。
2. 松手即可蓄力并展开高火力状态；移动会立即取消展开。
3. 前 4 波结束时战斗完全暂停，点选 3 张卡牌中的 1 张（无消耗、无广告）。
4. 第 5 波击败虫巢巨兽通关；死亡或超时则结算，可立即重玩。

每波之间额外修复 1 点装甲；抽卡可以获得新武器与额外回复。没有永久战力增长。

## 版权与部署

原创画面为代码生成的几何纹理，无第三方游戏素材。请勿直接使用其他作品的角色名称、纹理或商标素材。静态产物可以使用 Nginx 子路径部署；**不会自动改动旧游戏的地址**。

## 自动部署

复用旧项目 GitHub Actions → SSH/rsync 的 CI/CD：仅在 `main` 更新或手动触发时，构建并发布到独立的 `/var/www/endless-swarm/`，公开地址 `https://kk518.top/swarm/`。仓库 Secrets、服务器目录与 Nginx 路由已在首次部署中完成验证；缺少配置时工作流会跳过发布并显示警告，不影响旧游戏。详见 [部署说明](docs/DEPLOYMENT.md)。
