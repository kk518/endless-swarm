# 无尽虫潮 · Endless Swarm

> 一人，一甲，万千虫潮。

手机竖屏、单指操作的原创科幻虫潮生存 Roguelite。灵感来自经典俯视角虫潮/幸存者游戏，角色、敌人与视觉素材均为原创。

## 当前进度：M2 · 连杀热度与自爆虫（开发分支）

- 单指浮动摇杆 360° 移动（桌面支持 WASD / 方向键），自动锁敌、自动开火。
- 停止移动 0.8 秒进入动力装甲火力展开：伤害 ×1.35、射速 ×1.25；移动立即取消。
- **五波完整战斗**：前四波按计时推进，第五波击败虫巢巨兽通关。
- **每波结束免费三选一**：19 张技能卡，武器、火力、站桩、机动与生存流派。
- 四种自动武器：电磁步枪、散射炮、电弧线圈、火焰喷射器；最多四把同时装备。
- 工虫、跃袭虫、装甲虫、喷酸虫、**自爆虫**（第三波起加入，预警 0.85 秒后爆炸）、虫巢巨兽（第五波首领）。
- **连杀增伤**：4.5 秒内持续击杀累计连杀，5 / 10 / 20 连杀触发 +10% / +20% / +30% 伤害；受到攻击会中断连杀。
- **三张新卡**：战斗狂热（强化连杀伤害）、战地回收（每 20 杀回血）、弱点扫描（最多 42% 双倍暴击）。
- 命中特效、虫族预警、装甲血量、首领血条、击杀计数、结算与一键重开。
- Phaser 3 + TypeScript + Vite，纯前端静态站点，无账号和后端依赖。

本版本仍属于**可玩性原型**。M2 需要在真机上验证自爆虫的预警可读性、连杀数值、帧率、移动端兼容和构筑平衡；PR 合并前不会自动部署到生产。

## 本地运行

需要 Node.js 22+：

```bash
npm install
npm run dev
```

用手机和电脑处于同一个局域网时，访问开发机的 IP 与 Vite 输出端口；建议手机使用竖屏。

```bash
npm test           # Node 内置测试运行器（M0 + M1 + M2 纯规则测试）
npm run typecheck  # TypeScript 严格模式检查
npm run build      # 静态构建输出 dist/
npm run preview    # 预览构建结果
```

CI 在 PR / feature 分支和 main 上运行测试、类型检查与构建，成功后上传静态产物。

## 游戏流程

1. 点「进入战场」，拖动下半屏摇杆移动，武器持续自动攻击。
2. 松手即可蓄力并展开高火力状态；移动会立即取消展开。
3. 前 4 波结束时战斗完全暂停，点选 3 张卡牌中的 1 张（无消耗、无广告）。
4. 第 5 波击败虫巢巨兽通关；死亡或超时则结算，可立即重玩。

每波之间额外修复 1 点装甲；抽卡可以获得新武器与额外回复。没有永久战力增长。

## 版权与部署

原创画面为代码生成的几何纹理，无第三方游戏素材。请勿直接使用其他作品的角色名称、纹理或商标素材。静态产物可以使用 Nginx 子路径部署；**不会自动改动旧游戏的地址**。

## 自动部署

复用旧项目 GitHub Actions → SSH/rsync 的 CI/CD：仅在 `main` 更新或手动触发时，构建并发布到独立的 `/var/www/endless-swarm/`，公开地址 `https://kk518.top/swarm/`。仓库 Secrets、服务器目录与 Nginx 路由已在首次部署中完成验证；缺少配置时工作流会跳过发布并显示警告，不影响旧游戏。详见 [部署说明](docs/DEPLOYMENT.md)。
